# 数字人、世界模型与互动作品研究日报：2026-10-10

检索窗口：2026-10-04 至 2026-10-10。  
信息截点：2026-10-10（Asia/Shanghai）。已与 10 月 9 日及此前日报去重；本日新增主要来自 arXiv 10 月 9 日发布列表，论文实际提交时间集中在 10 月 7—8 日。

## 1. 本日摘要

本日最强信号不是单个生成模型，而是 AgentGarten 提出的系统分工：代码和传统引擎维护对象、规则、目标与权威状态，神经视频模型只把深度和法线实时渲染成逼真的第一人称观察；这是“代码编排持续运行的生成世界”目前最完整的公开实现之一。

AgentGarten 已开放 Apache-2.0 的渲染训练与流式推理代码以及受 OpenMDW 1.1 约束的权重，但代码世界、交互服务器和 agent 实践循环仍在 TODO，因此应视为“核心渲染器已开源、完整产品未开放”，不能等同于可直接部署的生成式游戏平台。

世界模型研究同时沿两条路线分化：WorldGuide、ME-World 继续生成可观看的未来视频；PLaW-VLA、LiteNWM 则只预测任务相关 latent，用结构化状态和评分替代像素级 rollout，以显著降低控制延迟。

LiteNWM 是本周期较强的工业信号：作者不仅报告 RTX 5090 上相对生成式导航世界模型的 128 倍端到端加速，还给出真实机器人在未知室内外环境中的闭环导航实验；不过代码、功耗和控制频率尚未披露。

数字人方面，GHARP 将身份重建与运行时表情残差解耦，并针对移动端设计轻量动画网络；但论文公开证据主要仍是 A100 上最多 13 倍加速，缺少手机实测、SDK 和资产导出链路。

“多参考身份”也成为新方向：Expression-Diverse References 说明强表情下，相对单张中性照的识别相似度本身就可能失真，并用表情多样的参考集同时改善生成条件和身份评测。

USDCraft 展示了 coding 与仿真的另一条实用链路：LLM 编写和修订可执行资产程序，输出带碰撞体、质量、关节及限位的 USD 资产，再直接进入 Isaac Sim；作者还给出了仅用仿真数据训练后在真实抽屉和烤面包机上的策略实验。

整体证据仍以作者论文、项目 demo 和开放代码为主，本周期未发现新的独立客户试点或规模化生产部署；除 AgentGarten 渲染器外，大多数新增尚不能直接复现。

## 3. 最值得关注的 10 个进展

### 1. AgentGarten：代码保存世界，神经模型负责把它显示出来

- **类型 / 日期 / 主线：**论文、GitHub、权重、demo；2026-10-08；世界模型、Coding × 互动作品。
- **官方链接：**[论文](https://arxiv.org/abs/2610.12374)、[项目页](https://mirros-lab.github.io/agent-garten/)、[GitHub](https://github.com/MirroS-Lab/AgentGarten)、[渲染器权重](https://huggingface.co/MirroS-Lab/AgentGarten-renderer)。
- **相对上期：**首次收录，是昨日“代码持有状态”趋势的完整系统化版本。
- **核心贡献：**模拟器或游戏引擎维护持久状态和程序化规则，导出深度、法线等结构条件；经 Adversarial Forcing 蒸馏的视频模型分块生成视觉观察。Agent 完成一轮交互后把经验写入 `playbook.md`，供下一轮继承。
- **Coding 接口：**公开 `Cosmos3Stream`、bounded KV cache、Triton kernel、cuBLAS、CUDA Graph 和训练 manifest；每个视频块提交后即可作为下一块历史。
- **互动与工业场景：**生成式训练环境、多人协作 NPC、机器人视觉仿真、品牌互动世界、规则可靠但视觉风格可切换的游戏。
- **边界：**渲染代码和权重已开放；代码世界、实时前端及 agent 实践循环尚未开放。项目称“实时”，但未公开统一硬件下的端到端动作延迟、并发或成本。
- **成熟度 / 证据 / 重要性 / 阅读：**部分开源研究系统；官方代码与作者实测；高；必读。

### 2. USDCraft：LLM 编写可执行 USD 资产程序

- **类型 / 日期 / 主线：**论文、交互 demo、资产；2026-10-08；Coding × 仿真、工业应用。
- **官方链接：**[论文](https://arxiv.org/abs/2610.11322)、[项目页](https://xingyoujun.github.io/usdcraft/)。
- **相对上期：**首次收录；比此前“视频转关节物体”更强调可执行程序和物理参数。
- **核心贡献：**LLM 根据文本、图片或残缺 mesh 编写资产程序，通过几何重编码发现误差并迭代修订，最终生成带质量、碰撞体、关节和限位的 USD 资产。
- **Coding 接口：**资产程序、USD/USDZ、Isaac Sim、PhysX、Diffusion Policy；网页提供 16 类可检查和下载的示例资产。
- **互动与工业场景：**数字孪生道具、机器人训练场景、游戏可交互物体、仓储设备仿真、虚拟制作预演。
- **关键结果：**项目报告每项任务采集 200 个仿真演示；USDCraft 资产训练的策略在真实开抽屉、压下烤面包机拨杆、启动烤面包机上分别达到 90%、85%、85%。
- **边界：**代码与数据仍标为 TODO；数字由作者实验给出，尚无第三方复现。
- **成熟度 / 证据 / 重要性 / 阅读：**可检查 demo、实机研究验证；论文实测；高；必读。

### 3. WorldGuide：把视频生成改造成闭环任务执行

- **类型 / 日期 / 主线：**论文、dataset/benchmark；2026-10-08；世界模型、互动内容。
- **官方链接：**[论文](https://arxiv.org/abs/2610.12459)。
- **相对上期：**首次收录；从动作条件视频推进到“观察结果后决定下一步”。
- **核心贡献：**Planner 根据目标和已生成状态预测下一原子动作或 `DONE`，Executor 生成对应视频片段，再把结果送回 Planner；分层视觉记忆以固定 token 预算保存长任务状态。
- **Coding 接口：**可映射为 `observe → plan(action|done) → generate → verify → loop` 状态机；但尚未见官方代码或服务 API。
- **关键结果：**作者报告 WorldGuide-Bench 任务成功率 33.33%，MiniMax-H3 在提供参考动作计划时为 29.90%；VideoCraft-Bench goal-only 条件下分别为 47.69% 与 32.73%。
- **场景：**互动教学视频、程序化操作演示、生成式解谜、分支剧情、可观察中间结果的任务模拟。
- **成熟度 / 证据 / 重要性 / 阅读：**研究原型；论文实测；高；必读。

### 4. LiteNWM：不生成未来画面，只评分未来轨迹

- **类型 / 日期 / 主线：**论文、真实机器人实验；2026-10-08；世界模型、机器人。
- **官方链接：**[论文](https://arxiv.org/abs/2610.12368)。
- **相对上期：**首次收录；进一步验证“世界模型不必输出 RGB”。
- **核心贡献：**多个候选轨迹共享一次视觉编码，并行预测不同时间尺度的 action-conditioned latent，再由 scorer 选择轨迹。
- **Coding 接口：**可作为 NoMaD、MBRA 等 trajectory proposer 后面的通用 evaluator，保持传统导航控制器和安全栈不变。
- **关键结果：**作者报告 RTX 5090 上端到端加速 128 倍；真实未知环境中，相对 NoMaD 的成功率由 43.3% 提升至 83.3%。
- **场景：**仓储移动机器人、室外巡检、配送机器人、空间计算导航。
- **成熟度 / 证据 / 重要性 / 阅读：**实机研究验证；论文实测；高；必读。

### 5. GHARP：少图身份建模与轻量实时动画解耦

- **类型 / 日期 / 主线：**论文；2026-10-07；数字人、3D Gaussian。
- **官方链接：**[论文](https://arxiv.org/abs/2610.10945)。
- **相对上期：**首次收录；补充昨日以 2D/视频扩散为主的实时数字人路线。
- **核心贡献：**离线身份阶段融合少量视图得到固定大小的 canonical Gaussian；运行时只预测表情相关残差，并以 body alignment 缓解表情码不包含身体和服装状态造成的模糊、闪烁。
- **Coding 接口：**理论上可把摄像头表情码、ARKit blendshape 或动捕信号映射到运行时残差，但论文未提供 SDK。
- **关键结果：**作者称在 Ava-256 上达到最佳质量，同时在 A100 上最多快 13 倍、Gaussian 数减少 8 倍。
- **边界：**“针对移动端优化”是结构目标，当前公开摘要没有真机 FPS、功耗或内存数字。
- **成熟度 / 证据 / 重要性 / 阅读：**研究原型；论文实测；中高；必读。

### 6. ME-World：多主体必须生活在同一个生成世界里

- **类型 / 日期 / 主线：**论文、评测指标；2026-10-08；世界模型、多 agent。
- **官方链接：**[论文](https://arxiv.org/abs/2610.12299)。
- **相对上期：**首次收录；由多摄像机一致性推进到多主体动作相互影响。
- **核心贡献：**把多个第一人称视频流放入同一 token 序列联合去噪，用所有主体的目标视角姿态和共享环境记忆约束生成；新增环境、状态更新与身份一致性指标。
- **Coding 接口：**游戏服务器可提交各 agent 的动作和目标位姿，模型返回同步 ego streams；权威对象状态仍应由服务器或模拟器维护。
- **场景：**多人生成式游戏、协作机器人仿真、第一人称互动电影、多角色训练环境。
- **成熟度 / 证据 / 重要性 / 阅读：**论文原型，无官方代码入口；作者实测；高；可读。

### 7. Memory Forcing：固定 KV 容量下保留中期事件

- **类型 / 日期 / 主线：**论文、推理基础设施；2026-10-08；流式视频、世界模型记忆。
- **官方链接：**[论文](https://arxiv.org/abs/2610.11756)。
- **相对上期：**首次收录；与昨日 LEDGER 的显式对象账本互补，解决模型内部“中期遗忘”。
- **核心贡献：**将固定缓存分成 sink、archive、working 三个区，以 Archive & Working Banks 保存多样中期事件；Bank-aware RoPE 在注意力阶段重映射时间位置。
- **Coding 接口：**可作为 causal video inference loop 的 cache policy，不改变缓存上限；适合和动作事件、镜头脚本共同调度。
- **场景：**角色离开后返回、互动直播中的长期场景保持、连续游戏画面、长镜头生成。
- **成熟度 / 证据 / 重要性 / 阅读：**论文原型；作者实测；中高；必读。信息截点前未核验到对应官方代码入口。

### 8. PLaW-VLA：只预测与任务相关的未来表示

- **类型 / 日期 / 主线：**论文；2026-10-08；世界模型、VLA。
- **官方链接：**[论文](https://arxiv.org/abs/2610.12285)。
- **相对上期：**首次收录。
- **核心贡献：**在预训练 prediction-oriented latent 空间中预测未来，以结构化因果注意力将观察历史、任务语义和未来状态共同输入动作生成器，避免重建无关视觉细节。
- **Coding 接口：**世界模型作为 VLA 内部预测模块；外部仍由机器人 runtime 负责动作限位、碰撞检查、执行与回滚。
- **关键结果：**作者报告 RoboTwin Hard Horizon III 相对 reactive policy 提升 11.8 个百分点，推理延迟约为生成式 WAM 的 1/19。
- **成熟度 / 证据 / 重要性 / 阅读：**研究原型；论文实测；中高；可读。

### 9. LAC-WM：用统一 latent action 跨越机器人本体差异

- **类型 / 日期 / 主线：**论文；2026-10-07；机器人世界模型。
- **官方链接：**[论文](https://arxiv.org/abs/2610.10846)。
- **相对上期：**首次收录。
- **核心贡献：**不直接以各机器人互不兼容的显式动作向量作为条件，而是学习跨 embodiment 的 latent action 空间，再适配新机器人。
- **Coding 接口：**每种机器人只需维护自身动作编码器/解码器；共享世界模型消费统一 latent action。
- **关键结果：**作者报告相对显式动作条件基线，在灵巧操作和改造后的 LIBERO 上最多提高 46.7% 与 11.7%。
- **场景：**多型号机械臂共用仿真器、跨机器人技能迁移、通用策略评测。
- **成熟度 / 证据 / 重要性 / 阅读：**研究原型；论文实测；中高；可读。

### 10. Expression-Diverse References：强表情下的身份保持不能只看中性照

- **类型 / 日期 / 主线：**论文、评测方法；2026-10-08；数字人、身份一致性。
- **官方链接：**[论文](https://arxiv.org/abs/2610.11023)。
- **相对上期：**首次收录；补充昨日 HiFD 的身份治理与评测路线。
- **核心贡献：**构建覆盖轻度、强烈和极端表情的参考图库；单图输入时先用面部 reenactment 模型合成多种表情，再以整组参考条件化 Stand-In 并评测身份。
- **Coding 接口：**可作为数字人资产注册环节：授权照片经过表情扩展，形成条件库和上线回归测试集。
- **场景：**情绪化数字演员、游戏角色、直播数字人、跨镜头身份验收。
- **边界：**合成参考也可能放大身份偏差；未见代码、权重或肖像授权机制。

## 4. 数字人 / 虚拟形象能力进展

- **生成与驱动：**GHARP 代表显式 3D 资产路线：身份几何离线生成，表情残差在线驱动。它与昨日 PixReenact 的持续像素生成不同，更适合需要自由视角和传统渲染管线的场景。
- **3D/4D 表示：**固定大小 canonical Gaussian 有利于部署和缓存，但 GHARP 仍是头肩级表现，未解决完整身体、手势、服装动态和跨镜头动作。
- **实时交互：**论文证明了相对速度优势，尚未证明端到端手机实时。表情捕捉、语音到表情、RTC、打断和并发仍需外部组件。
- **音视频与情感表达：**Expression-Diverse References 说明强情绪不仅是动作控制问题，也改变身份特征的可观察方式；数字人评测需要按表情强度分层。
- **工程部署：**本日数字人新增均未提供正式 API、Unity/Unreal 插件或可复现服务。真正接近产品的仍是昨日已报的 TalkLikeYou 浏览器 demo。
- **安全与身份治理：**多参考图库能改进身份回归，但不能替代授权、撤回、水印和溯源。本周期没有新的生产级肖像治理方案。

结论：3D 数字人的运行时表示正在变轻，但“移动端可验证实时”和“可打断全双工交互”仍没有由同一开放项目完成。

## 5. 世界模型进展

- **架构与训练：**AgentGarten 将视频模型训练为几何条件神经渲染器；PLaW-VLA、LiteNWM 则完全绕过 RGB 生成。世界模型正在分为“面向人观看的渲染模型”和“面向控制器决策的 latent 模型”。
- **可控 / 可玩生成：**WorldGuide 用原子动作闭环推进任务；AgentGarten 从程序化世界接收结构条件；两者都比一次性文本提示更接近持续交互。
- **长时与物理一致性：**Memory Forcing 保存中期视觉事件，AgentGarten 把真正的持久状态交还代码世界。这两者的可靠性层级不同：缓存提高视觉连续性，代码状态才能提供确定的规则和对象真值。
- **空间与多主体：**ME-World 开始联合生成多个主体的同步观察，但没有证据表明它能取代权威服务器；较安全的工程方式是让服务器保存共享状态，模型只生成各玩家画面。
- **机器人 / 游戏 / 仿真：**LiteNWM、PLaW-VLA、LAC-WM 强调低成本 foresight；USDCraft 则解决世界模型和仿真需要大量可交互资产的上游瓶颈。
- **实时部署：**bounded KV、分块提交、latent scoring 和动作空间统一是本日主要部署信号。批处理、多人并发、故障恢复及确定性回放仍未报告。
- **评测：**WorldGuide 用任务完成率，ME-World 用共享世界一致性，LiteNWM 用真实导航成功率；评价标准正从单纯视频质量转向在线行为结果。

## 6. Coding × 新型互动作品

### 链路一：规则可靠、画面生成的互动世界

**键盘或 agent 动作 → 代码世界更新对象/物理/任务 → 导出深度与法线 → AgentGarten 流式渲染 → 新观察返回用户或 agent**

代码持有权威状态、碰撞、计分和任务完成条件；生成模型负责外观、材质和现实感；传统引擎负责确定性物理。渲染器代码和权重已开放，但完整世界服务器与前端尚未开放。

### 链路二：会观察执行结果的互动教程或生成式解谜

**用户目标 → WorldGuide Planner 选择原子动作 → Executor 生成片段 → 视觉记忆更新 → Planner 决定继续或结束**

代码负责循环、超时、审计和失败恢复，模型负责动作规划及视频化执行。已有论文任务成功率证据，但没有可运行 API；当前更适合作为研究原型，而非生产工作流。

### 链路三：多玩家各自看到同一个生成世界

**权威服务器状态 + 多 agent 动作/目标位姿 → ME-World 联合生成 ego streams → RTC 分发给不同玩家**

联合去噪帮助各视角保持身份与状态更新一致；服务器仍需处理物品归属、作弊防护和回滚。论文证明多视角一致性改善，网络同步和真实多人延迟属于本报告推断。

### 链路四：从一句话生成可交互工业资产

**文本/图片/扫描 mesh → LLM 编写资产程序 → 几何检查与代码修订 → USD/PhysX → Isaac Sim → 策略训练或互动应用**

生成模型负责补全对象结构并写程序；代码表示明确部件、关节和物理属性；PhysX 验证实际交互。项目已有下载资产和实机任务结果，但生成器代码尚未开放。

### 链路五：低延迟未来评估器

**导航策略提出 K 条轨迹 → LiteNWM 共享编码并行预测 latent future → scorer 排序 → ROS2/传统控制器执行**

模型只承担“哪条路线后果更好”，不负责渲染画面；代码负责候选生成、安全门禁和电机控制。已有真实机器人证据，是本日最接近工业部署的世界模型链路。

### 链路六：自由视角的端侧数字角色

**相机/ARKit 表情 → expression code → GHARP 残差网络 → canonical Gaussian → 移动 GPU 渲染 → WebRTC/游戏引擎**

身份资产离线构建，运行时只更新表情残差，可降低带宽和算力；但 Unity/Unreal 接口、手机帧率和完整语音交互均未提供，现阶段属于明确的工程机会而非现成产品。

## 9. 系统架构与技术趋势判断

明显升温的方向是“外置权威状态”。AgentGarten 把世界状态和规则交给代码，LEDGER 把离屏对象放入显式账本，USDCraft 把物体结构写成可执行资产程序。单靠视频模型隐式记住一切的路线正在降温。

第二个主流趋势是双运行时：面向用户的互动作品需要可观看神经渲染；面向机器人和 agent 的决策系统更偏向 LiteNWM、PLaW-VLA 一类 latent future。两者可以共享状态，但不必共享输出表示。

可复用架构正在收敛为：

**权威状态/规则层 → agent 或规划层 → 结构化动作与几何条件 → 世界模型或数字人表演层 → RTC/渲染输出 → verifier 与事件日志**

其中代码负责确定性和审计，传统引擎负责物理、碰撞与网络同步，生成模型负责难以手工制作的视觉表现、动作先验和未来评分。

仍未解决的问题包括：多人条件下的稳定帧率和成本；长时间身份、声音及空间一致性；模型故障后的确定性回滚；代码世界与神经渲染之间的遮挡、接触和细粒度物理对齐；数字人授权、水印和删除请求传播。

营销风险主要集中在“实时”和“开放”两个词：GHARP 没有移动设备数据；AgentGarten 没有端到端延迟和并发数据，且完整交互世界尚未开放；USDCraft 的代码与数据仍是 TODO；ME-World、WorldGuide 的 demo 能力不应被解读为生产部署。

## 10. 论文精读候选

1. [AgentGarten](https://arxiv.org/abs/2610.12374)

   - **值得读：**最贴近“coding 驱动持续生成世界”的系统。
   - **重点：**结构条件接口、Adversarial Forcing、精确历史 replay、agent playbook 实验。
   - **差异：**世界状态不由视频模型隐式承担。
   - **风险：**完整 code world 未开放，论文结果不能全部端到端复现。

2. [USDCraft](https://arxiv.org/abs/2610.11322)

   - **值得读：**把代码生成、3D 资产、物理仿真和实机策略连成完整链路。
   - **重点：**source geometry analysis、iterative geometric rechecking、物理参数生成、Real2Sim2Real。
   - **差异：**输出不是静态 mesh，而是可执行、可检查的资产程序。
   - **风险：**代码和数据未开放，LLM 及推理成本需核验。

3. [WorldGuide](https://arxiv.org/abs/2610.12459)

   - **值得读：**把视频生成改写为闭环程序执行。
   - **重点：**Planner/Executor 联合数据、`DONE` 判断、分层记忆、任务成功率协议。
   - **差异：**下一动作由已生成结果决定，而非预先给定完整脚本。
   - **风险：**任务成功评测可能受 judge、训练任务覆盖和微调协议影响。

4. [LiteNWM](https://arxiv.org/abs/2610.12368)

   - **值得读：**同时提供延迟和真实机器人结果。
   - **重点：**共享候选编码、多时间尺度 latent、scorer 可迁移性、实机协议。
   - **差异：**不生成 RGB，直接服务候选轨迹选择。
   - **风险：**128 倍来自特定硬件和对照系统，需复核绝对控制周期。

5. [GHARP](https://arxiv.org/abs/2610.10945)

   - **值得读：**数字人部署中清晰的离线/在线解耦。
   - **重点：**canonical Gaussian、语义 latent、表情残差、body alignment、设备性能表。
   - **差异：**以固定大小重建先验降低运行时复杂度。
   - **风险：**无代码和真机证据，头肩范围限制实际用途。

## 11. 下周跟踪与可行动建议

继续追踪：

1. AgentGarten 何时开放 code worlds、互动服务器与 agent practice loop。
2. AgentGarten 在单张 H100、L40S、RTX 5090 上的首块延迟、稳态 FPS、显存与多人并发。
3. GHARP 是否发布代码、移动端实测、Unity/Unreal 或 WebGPU 接口。
4. WorldGuide 是否开放 WorldGuide-Bench、训练代码和确定性的 task-success evaluator。
5. ME-World 的多流生成成本是否随主体数线性或超线性增长。
6. LiteNWM 的绝对控制频率、板载功耗及安全控制器介入比例。
7. USDCraft 代码、数据和资产许可证，以及程序失败时的自动几何/物理验证覆盖率。
8. 多表情身份参考是否改善人类身份判断，而不只是 face-recognition embedding 指标。

本周可执行实验：

- **实验一：代码世界—神经渲染最小闭环。**  
  目标是验证 AgentGarten 的真实接口边界。用简单可脚本化场景输出深度和法线，接 `Cosmos3Stream` 连续生成 30 秒；记录首块、稳态块延迟、显存和动作转折后的响应。成功判据是生成始终快于播放速度，且三次转向均在下一视频块体现。

- **实验二：可执行资产验收。**  
  从 USDCraft 下载一个关节 USDZ，导入 Isaac Sim，自动遍历所有关节限位并运行碰撞、质量和稳定性检查。成功判据是无需人工修模即可完成加载、关节 sweep 和 100 次物理仿真。

- **实验三：RGB rollout 与 latent evaluator 对照。**  
  在同一导航数据上比较视频世界模型和轻量 latent scorer，测候选排序准确率、单步延迟、显存及错误类型。成功判据是在成功率下降不超过 5 个百分点的前提下，将评估延迟降低至少一个数量级。

- **实验四：数字人强表情身份回归。**  
  为一个已授权角色建立中性单图与多表情参考集，在 TalkLikeYou 或现有 avatar 管线上生成轻度、强烈、极端表情片段。分别计算单图和图库身份相似度，并进行盲测。成功判据是多参考评测与人工身份判断的相关性提高，同时不掩盖明显身份漂移。
