## 1. 本日摘要

本日高质量增量明显集中在机器人世界动作模型，而非数字人。最值得注意的技术变化是：未来预测正在从高成本 RGB 视频转向深度、点轨迹、DINO 特征、骨骼控制和全身控制意图等结构化状态；ModAR 的实验甚至显示，在其任务上移除未来 RGB 并未降低成功率。XPACE 则进一步把世界模型同时作为机器人策略、动作条件模拟器和恢复数据生成器，在 XPENG IRON 实机上形成“观察—想象失败—合成恢复轨迹—再训练策略”的闭环。

实时性方面，DIDO 将四步视频世界模型蒸馏为单步推理，作者报告 H100 上端到端延迟约 384 ms；EVOKE 更新了 Turbo 权重和交互 UI，五张 H200 可在约 1.34 秒生成 1.5 秒视频，但仍是昂贵的准实时。空间世界模型出现另一条路线：AlayaVista 不维护无限增长的透视历史，而是维护 360° 全景 latent，再按相机视口局部渲染和细化。

工业接口正在变得更清晰：代码负责权威状态、动作协议、安全门、数据过滤和设备执行；世界模型负责结构化未来、候选后果和恢复样本；传统控制器负责稳定、碰撞和硬实时闭环。与此同时，“When the World Lies”证明下载的世界模型 checkpoint 本身可能成为供应链攻击入口，即使下游策略只在干净数据上训练也可能被触发劫持。

数字人方向相对昨日没有新的高质量发布；MGAvatar、SignMimic 和 MoVT 仍是本窗口内主要研究增量，但今天没有可验证的新权重、实时 API 或生产部署。因此，本期不重复列为重点条目。整体产业信号是：世界模型正在从“能生成未来画面”转向“能否改善动作、恢复和安全决策”；不过除少数实机实验外，主要证据仍来自作者评测，代码、SLA、成本和第三方复现明显不足。

## 3. 最值得关注的 10 个进展

### 1. ModAR：结构化未来比生成 RGB 更能帮助机器人动作

- **类型 / 日期 / 主线：**论文、世界动作模型；2026-09-15；世界模型、实时运行时。
- **官方链接：**[论文](https://arxiv.org/abs/2609.17524)。
- **相对上期：**新增；论文在上期信息截点后进入可检索状态。
- **核心贡献：**按“点轨迹 → DINO 特征 → 深度 → RGB → 动作”顺序自回归去噪。作者实验中，删除点轨迹、DINO、深度分别降低成功率，而删除未来 RGB 不产生一致下降。30.1M 参数 ModAR 在受控比较中取得 75%，对照 6B Flex-π 为 72%，训练 FLOPs 约少 20 倍。
- **Coding 接口：**输入当前多模态观测、任务和机器人状态，输出未来结构状态及动作；适合作为 ROS/策略服务器中的异步推理节点。
- **场景：**双臂操作、低成本机器人策略、无动作标签人类视频迁移。
- **成熟度 / 证据：**实机研究原型；作者报告 RTX 5090 上 147.9 ms、6.76 Hz，三项实机任务总体成功率 83.3%。代码未见稳定公开入口。
- **重要性 / 阅读：**高 / 必读。

### 2. XPACE：世界模型为机器人生成“如何从失败中恢复”的训练数据

- **类型 / 日期 / 主线：**论文、实机系统；2026-09-15；世界模型、工业应用。
- **官方链接：**[论文](https://arxiv.org/abs/2609.17372)。
- **相对上期：**新增。
- **核心贡献：**共享视频 backbone 同时支持两种模式：策略模式联合预测未来视频和可执行动作；模拟器模式根据骨骼控制和相机 pose 预测后果。模拟器围绕专家轨迹合成偏离—恢复片段，经 DINOv3、PSNR、SSIM 过滤后回灌策略训练。
- **Coding 接口：**`观察/任务 → 动作块 + 未来视频`，以及 `历史 + skeleton controls + camera pose → rollout`；适合接入 DAgger、策略评测和失败回放系统。
- **场景：**人形机器人训练、异常恢复、低成本实机数据扩增。
- **成熟度 / 证据：**XPENG IRON 实机研究 PoC；作者实测。论文显示约 5000 小时异构视频训练，但未开放代码、权重或生产运行时。
- **重要性 / 阅读：**高 / 必读。

### 3. EVOKE-Turbo：从论文概念推进到权重、交互 UI 和可复现脚本

- **类型 / 日期 / 主线：**GitHub、模型权重、交互 UI；2026-09-11—12 更新；世界模型、Coding。
- **官方链接：**[代码](https://github.com/AlayaLab/Evoke)、[论文](https://arxiv.org/abs/2608.13546)。
- **相对上期：**实质更新；基础论文曾在 8 月日报报道，本次新增 Turbo 权重、WBench 结果和交互探索 UI。
- **核心贡献：**保持外部、相机索引的 world-state bank；Turbo 仍为三步、无 CFG，WBench 平均分由 80.821 升至 82.0。UI 支持逐段 prompt、双摇杆相机、流式预览、继续生成和分支修订。
- **Coding 接口：**shell/Python launcher、分段 prompt schedule、相机 pose、i2v/v2v 模式及本地 Web UI。
- **场景：**生成式展馆、环境预演、可导航视觉故事、互动世界导演台。
- **成熟度 / 证据：**Apache-2.0 代码和权重已开放；五张 H200 平均 1.34 秒生成 1.5 秒、单 H200 为 2.11 秒，仍未覆盖输入到显示的 p95 延迟。
- **重要性 / 阅读：**高 / 必读。

### 4. AlayaVista：360° latent 保存世界，视口只生成用户正在看的部分

- **类型 / 日期 / 主线：**论文、dataset、项目 demo；2026-09-13；世界模型、空间计算。
- **官方链接：**[论文](https://arxiv.org/abs/2609.14462)、[项目页](https://alaya-lab.github.io/AlayaVista/)、[GitHub](https://github.com/AlayaLab/AlayaVista)。
- **相对上期：**新增漏项。
- **核心贡献：**先从单图扩展全景先验，再演化相机条件的 360° latent；latent viewport renderer 只抽取目标视口，局部 refiner 负责细节和超分。配套 MUGEN 含 1318 小时、至少 4K 的全景视频，以及深度、相机轨迹、实例掩码和语义标注。
- **Coding 接口：**相机 pose 是明确控制协议，可由游戏引擎、WebXR 或 coding agent 生成。
- **场景：**自由视角预演、虚拟旅游、空间品牌体验、生成式 XR。
- **成熟度 / 证据：**论文 demo；仓库目前只有说明文件，推理代码和权重仍在 roadmap。
- **重要性 / 阅读：**高 / 必读。

### 5. WholeBodyWAM：把预训练 WAM 扩展至人形机器人全身移动与操作

- **类型 / 日期 / 主线：**论文、项目 demo；2026-09-15；世界模型、机器人。
- **官方链接：**[论文](https://arxiv.org/abs/2609.16644)、[项目页](https://wholebodywam.github.io/)。
- **相对上期：**新增。
- **核心贡献：**同时预测视觉未来、机械臂操作动作和 whole-body controller 意图，并对不同 WBC 的控制语义进行显式 grounding。作者报告仿真总体成功率 91.9%，实机 OOD 任务进度提高 0.23，不同 WBC 间成功率方差降低 70%。
- **Coding 接口：**上层模型输出 WBC-grounded intent，由传统 whole-body controller 负责平衡、步态和关节约束。
- **场景：**移动取放、跨房间搬运、人形机器人服务。
- **成熟度 / 证据：**实机研究原型、作者实测；规模、延迟、硬件配置和代码完整度尚待核验。
- **重要性 / 阅读：**高 / 必读。

### 6. DIDO：把交互动力学压缩到一次去噪

- **类型 / 日期 / 主线：**论文、推理加速；2026-09-14；世界模型、支撑基础设施。
- **官方链接：**[论文](https://arxiv.org/abs/2609.15570)。
- **相对上期：**新增漏项。
- **核心贡献：**发现背景在早期去噪步骤已稳定，而夹爪、物体及接触关系收敛较慢；因此通过分布匹配蒸馏、边界框推理 token 和 DINOv3 多层特征对齐，将四步模型压缩为一步。
- **Coding 接口：**可作为机器人策略中的单次 `predict_future_and_action()` 调用，避免多轮 diffusion scheduler。
- **场景：**机械臂闭环操作、边缘端候选动作预测、实时数字孪生。
- **成熟度 / 证据：**作者报告 LIBERO 99.0%、LIBERO-Plus 76.6%、RoboTwin 92.0%；公开结果显示 H100 约 384 ms，对照教师约 562 ms。代码与权重未核验。
- **重要性 / 阅读：**高 / 必读。

### 7. When the World Lies：世界模型 checkpoint 成为控制系统供应链攻击面

- **类型 / 日期 / 主线：**论文、安全评测；2026-09-14；安全、工业部署。
- **官方链接：**[论文](https://arxiv.org/abs/2609.15781)。
- **相对上期：**新增。
- **核心贡献：**攻击者只需污染预训练世界模型 checkpoint，即可让下游在干净数据上训练的 Dreamer actor 或 MPC/CEM 规划器，在触发图案出现时自行“优化”到攻击者指定动作。最强设置中触发步骤劫持率达 100%，同时干净任务仍保留至少约 75% 成功率。
- **Coding 接口：**直接影响模型注册、哈希签名、checkpoint provenance、红队触发测试和部署 CI。
- **场景：**机器人、自动驾驶、工业控制和第三方模型市场。
- **成熟度 / 证据：**论文攻击原型；作者实测，尚无真实设备攻击。
- **重要性 / 阅读：**高 / 必读。

### 8. WLA³：用统一 latent action 连接人类视频、机器人轨迹和仿真数据

- **类型 / 日期 / 主线：**项目页、预印本预告；项目页约 2026-09-15 可检索，精确上线时间待核验；世界模型、数据基础设施。
- **官方链接：**[项目页](https://wla-3.github.io/)。
- **相对上期：**新增。
- **核心贡献：**把多视角世界状态变化压缩为 32 维 local latent action，并保留更丰富的 transition feature，供语义、动力学和运动学任务共享。官方报告六项实机任务平均成功率 81.9%，π0.5 为 66.2%。
- **Coding 接口：**latent action 可成为跨 embodiment 的中间动作协议，用于缓存、检索、组合和转换到具体机器人 action space。
- **场景：**人类示范到机器人迁移、多本体策略训练、动作资产复用。
- **成熟度 / 证据：**官方项目主张；arXiv 与代码仍显示“coming soon”，不可视为已开源。
- **重要性 / 阅读：**中高 / 仅跟踪。

### 9. Loss-Conditioned State Execution：模型提出变化，不代表系统应执行变化

- **场景：**库存控制、数字孪生状态更新、保守机器人执行。

## 4. 数字人 / 虚拟形象能力进展

- **生成与驱动：**相对 9 月 16 日无新的高质量新增。MGAvatar、SignMimic 和 MoVT 仍分别代表 mesh-Gaussian 头部、手语身份迁移和 2D 视频辅助 3D 动作词表，但今天未出现新权重或独立评测。
- **3D/4D 表示：**本日新增更偏向环境全景 latent，而不是人体 3D/4D。AlayaVista 对数字人的潜在价值在于提供持续空间背景，但没有人物身份或表情控制。
- **实时交互：**没有新的生产级语音数字人首帧时间、turn-taking、打断恢复或并发数据。
- **音视频与情感：**本周期暂无新的原生音视频数字人或情绪控制技术可核验。
- **工程部署：**现阶段更可落地的仍是“现有 RTC/LLM/TTS 数字人 + 新世界模型背景或物理层”，而不是让同一生成模型同时承担角色、环境和业务状态。
- **安全与身份治理：**数字人肖像授权、水印、撤回和深伪检测本日无新增。“When the World Lies”属于模型供应链安全，不能替代人物身份治理。

结论：数字人能力本日没有跨越式变化；新增价值主要来自世界模型和运行时，可为数字角色增加空间连续性、动作后果和失败恢复。

## 5. 世界模型进展

- **架构与训练：**从“视频模型加动作头”转向多种结构状态协同。ModAR 使用点轨迹、DINO 和深度；XPACE 使用骨骼与相机控制；WholeBodyWAM 使用 WBC 意图；AlayaVista 使用全景 latent。
- **可控 / 可玩：**EVOKE 已提供逐 chunk 改 prompt、双摇杆相机和分支修订；AlayaVista 的相机 pose 是明确控制量，但代码尚未开放。
- **长时与物理一致性：**EVOKE 的外部状态库与 AlayaVista 的全景状态都避免无限堆叠历史帧，不过两者仍依赖生成模型维护外观和动力学，不能视作权威物理数据库。
- **空间表示：**AlayaVista 的“全景世界状态 → 局部 viewport”适合用户视野驱动的渲染；ModAR 则说明机器人控制可完全不生成 RGB，只预测决策所需结构。
- **机器人 / 仿真：**XPACE 和 WholeBodyWAM 把 WAM 从桌面机械臂推向人形机器人；DIDO 聚焦推理延迟，ModAR聚焦表示效率。
- **实时部署与评测：**ModAR 147.9 ms、DIDO 384 ms、EVOKE 多卡 1.34 秒/1.5 秒是不同任务和硬件口径，不能直接横比。更合理的共同指标是闭环频率、动作成功率、p95 延迟、失败恢复和单位决策成本。

## 6. Coding × 新型互动作品

### 链路一：代码生成相机轨迹 → 全景状态 → 局部生成视口 → 自由探索空间

Three.js、Unity、Unreal 或 WebXR 保存玩家 pose、碰撞和权限；coding agent 生成下一段相机轨迹；AlayaVista 演化 360° latent 并只渲染目标视口。可形成自由视角品牌空间、虚拟旅游和互动电影摄影机。项目已有 demo，推理代码未开放，因此仍是研究链路。

### 链路二：事件脚本与摇杆 → EVOKE world-state bank → 逐段生成 → 可分支视觉世界

运行时把摇杆、镜头和剧情事件转成 pose 与 chunk prompt；外部状态库保存已访问空间；模型生成下一段视频；UI 保存分支和修订历史。可构建生成式展馆、视觉小说和导演式沙盒。代码、权重和 UI 已开放，但 GPU 成本和多用户同步尚未解决。

### 链路三：观察与任务 → ModAR结构化未来 → 动作 → 传统控制器执行

机器人代码采集深度、点轨迹和语义特征；ModAR依次预测未来结构并生成动作；传统控制器负责关节限位、插值和急停。模型不必渲染可观看视频，因此适合工业机械臂和双臂协作。已有实机论文证据，暂无完整开发包。

### 链路四：人类视频 / 实机数据 → XPACE模拟器 → 合成失败恢复 → 策略再训练

数据工程代码统一人类骨骼、相机 pose 和机器人 action；XPACE 模拟偏离专家轨迹的失败，再生成恢复片段；质量过滤器筛除未真正恢复的样本；策略通过 DAgger 式微调吸收有效轨迹。可用于人形机器人上线前的恢复训练，已有 XPENG IRON 实机证据。

### 链路五：世界模型候选 → 损失准入门 → 控制器或业务状态机

世界模型提出移动、更新或动作；Loss-Conditioned gate 依据校准数据评估“执行是否比保持不变更好”；只有置信下界为正才提交。适用于库存、数字孪生、机器人安全模式和互动作品中的高价值永久状态变化。方法已有统计实验，实时交互应用属于**本报告推断**。

### 链路六：第三方 checkpoint → 签名与触发测试 → 沙箱 rollout → 生产准入

模型注册系统校验来源、哈希和许可证；红队生成视觉触发图案；在 Dreamer/MPC 沙箱中比较干净与触发行为；只有通过审计的模型才能控制设备。该链路由“世界模型后门”论文直接提出风险依据，但完整工程规范仍需行业建立。

代码、模型和传统引擎的合理分工正在稳定为：

`用户/agent → 权威状态与动作协议 → 世界模型预测/生成 → verifier或准入门 → 规则/物理控制器 → 执行 → 观测回写`

## 9. 系统架构与技术趋势判断

**明显升温：**

1. 结构化未来替代完整 RGB：深度、轨迹、特征和控制意图成为主要状态。
2. 世界模型作为训练数据工厂：不仅预测，还主动生成失败与恢复样本。
3. 多层控制：生成模型提供高层动作或候选后果，传统控制器保持稳定和硬实时。
4. 外部空间状态：相机索引 point cloud、全景 latent 和 world-state bank 避免上下文无限增长。
5. 模型供应链安全：checkpoint 的签名、来源、触发测试将成为工业部署必需项。

**降温或被重新审视：**

- “生成得像”不再足以证明世界模型有用；
- 直接解码高清 RGB 未来并非所有机器人任务都需要；
- 单一平均视频质量指标无法反映干预忠实度、动作收益和后门风险；
- 宣称“实时”但只提供暖启动吞吐、不提供端到端 p95 的项目可信度下降。

**可复用系统架构：**

`状态采集 → 结构化表示 → 世界模型候选/rollout → 物理、损失与安全 verifier → 控制器/引擎执行 → 失败检测 → 恢复数据回灌`

**尚未解决：**

- 结构预测是否能跨环境、光照和机器人本体稳定泛化；
- 生成恢复数据是否会强化模拟器自己的系统性错误；
- 全景 latent 对动态物体、遮挡和重新进入视野的状态保持；
- 机器人世界模型缺少统一的 p95 延迟、单位动作能耗与故障恢复 benchmark；
- 数字人与世界模型仍缺乏统一的人物身份、业务状态和空间状态协议；
- 开源项目普遍缺少并发、可观测性、回滚和长期运行数据。

**营销与证据风险：**

AlayaVista 当前仓库没有推理代码或权重，不能称为已开源。WLA³ 的 arXiv 和代码仍未上线，指标仅属官方项目页主张。WholeBodyWAM、XPACE 和 DIDO 都有实机或基准证据，但尚不足以证明规模化部署。EVOKE 的多卡生成速度接近内容时长，不等于低延迟游戏渲染或多人服务。

## 10. 论文精读候选

1. [Modality-Autoregressive World-Action Models](https://arxiv.org/abs/2609.17524)：重点读 formulation comparison、modality order、RGB ablation 和 latency；它直接挑战“WAM 必须生成视频”。风险是任务规模有限且代码未开放。
2. [XPACE](https://arxiv.org/abs/2609.17372)：重点读双模式 backbone、self-gradient forcing、恢复轨迹生成与过滤；差异在于模拟器直接参与策略自我改进。风险是生成偏差闭环放大。
3. [AlayaVista](https://arxiv.org/abs/2609.14462)：重点读 panoramic latent、viewport renderer、few-step distillation 和 MUGEN 数据构建；适合研究空间世界状态。风险是代码和权重未发布。
4. [DIDO](https://arxiv.org/abs/2609.15570)：重点读区域收敛分析、interaction token 和 DINOv3 对齐；价值是把蒸馏目标从整体画面转向接触动力学。风险是 H100 上 384 ms 仍非硬实时。
5. [When the World Lies](https://arxiv.org/abs/2609.15781)：重点读 latent routing、Dreamer/MPC 攻击路径和 repair 实验；它将模型安全问题直接连接到物理执行。风险是当前验证仍以仿真控制任务为主。

## 11. 下周跟踪与可行动建议

**继续追踪：**

1. AlayaVista 是否开放推理代码、权重、MUGEN 数据及商业许可证。
2. ModAR 是否发布数据、模型，以及不生成 RGB 的结果能否在更复杂接触任务复现。
3. XPACE 的实机逐任务结果、约 10 Hz 运行时和失败恢复数据质量。
4. DIDO 的 384 ms 是否包含编码、动作解码和通信，及消费级 GPU 表现。
5. WholeBodyWAM 在不同 WBC、地形和负载下的稳定性。
6. EVOKE-Turbo 的单卡显存、输入到显示 p95、长时回访误差和并发成本。
7. 世界模型 checkpoint 后门是否能通过权重扫描、latent 异常检测或行为签名发现。
8. 数字人方向是否出现能与世界模型共享身份、动作、空间和业务状态的正式 SDK。

**本周可动手实验：**

1. **无 RGB 的小型 WAM。**目标：验证结构化未来是否足够支持动作。组件：RoboTwin/LIBERO、点轨迹、深度、DINO 特征、小型 DiT。难点：时间和坐标对齐。成功判据：删除 RGB 后成功率不下降超过 2 个百分点，同时延迟下降至少 30%。
2. **EVOKE 回访一致性测试。**目标：验证外部状态库。组件：EVOKE-Turbo、Interactive UI、固定闭环相机路径。难点：深度误差与动态物体。成功判据：离开场景 20 个 chunk 后返回，关键对象数量、位置和颜色仍满足预设规则。
3. **恢复轨迹数据闭环。**目标：复刻 XPACE 思路。组件：MuJoCo/Isaac Sim、现有策略、动作扰动、DINO 相似度过滤。难点：避免“看似恢复、实际不可执行”。成功判据：加入不超过 10% 合成恢复数据后，扰动测试成功率提升至少 10 个百分点且正常任务不退化。
4. **世界模型供应链门禁。**目标：建立 checkpoint 上线前审计。组件：内部模型注册表、触发图案集、Dreamer/MPC 沙箱、哈希与签名。难点：未知触发器搜索。成功判据：可自动比较干净/扰动观测下的动作分布，异常模型被阻止进入生产控制链。
