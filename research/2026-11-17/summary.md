# 数字人、世界模型与互动作品研究日报：2026-11-17

检索窗口：2026-11-11 至 2026-11-17。已对照 11 月 10–16 日日报去重；PAN 2 于 11 月 10 日发布、11 月 11 日由 MBZUAI 正式公告，因完整代码与权重在本周期进入可用状态且此前漏报，作为边界条目纳入。

## 1. 本日摘要

本期高质量增量不多，但新增内容的工程价值较强：数字人侧不再只追求短片画质，而是集中解决十分钟级误差积累和可打断语音交互。LongCat-Video-Avatar 1.6 公开权重与推理代码，通过长视频 rollout、on-policy distillation 和 DMD/OPSD LoRA 组合改善长时口型、身份和动作稳定性；不过“超过十分钟”仍是项目方演示，尚无独立长时评测。Haru-4B 则公开了可同时听与说的全双工语音底座，为数字人提供相觅、打断、重叠说话和角色声音控制，但它本身不生成头像画面，也不是可靠的指令型助手。

世界模型侧，PAN 2 把“语言模型规划事件、扩散模型渲染结果”落实为 Apache-2.0 的训练及推理栈，并直接提供 Codex/Claude Code 的结构化提示 skill；其作者评测中完整多步计划成功率为 34.0%，说明可用于候选计划预演，但远未达到可靠模拟器水平。华为云 CloudRobo-WM1.2 是今日最强产业信号：它把预测世界状态和动作生成放入同一机器人模型，并宣布开放模型、推理代码和昇腾训练框架；但截至检索时，精确对应 1.2 版本的公开仓库、许可证和权重仍未确认，不能按“已可复现开源”处理。

Coding × 互动作品的共同趋势更加清晰：语言或代码维护事件、角色和任务状态；生成模型负责声音、动作细节和视觉表现；传统引擎、机器人控制器及审核器负责权威状态、安全边界和失败回退。当前最可落地的是离线长视频数字人和本地全双工语音角色；逐帧可玩的生成世界、多主体实时数字人和真实机器人闭环仍缺可靠延迟、状态查询和独立部署证据。

## 3. 最值得关注的 4 个进展

本期仅发现四项同时满足日期、相关性和一手证据要求的实质新增，未用旧闻补足 8–12 项。

### 1. LongCat-Video-Avatar 1.6：开放十分钟级音频驱动数字人

- **类型 / 日期 / 主线：**模型、权重、GitHub；11 月 15 日；数字人。
- **官方链接：**[GitHub与推理代码](https://github.com/meituan-longcat/LongCat-Video)、[模型卡与权重](https://huggingface.co/meituan-longcat/LongCat-Video-Avatar-1.6)。
- **相对上期：**首次收录；11 月 16 日日报未覆盖该项目。
- **核心贡献：**在 1.5 架构上加入面向长视频的 rollout、强化学习、改进CFG的DMD少步蒸馏和on-policy distillation。官方称可生成超过十分钟的视频，并减少自回归续写中的口型抖动、身份漂移和误差累积。
- **Coding接口：**支持音频＋文本、音频＋图像、视频续写和多人音频；通过JSON配置、`torchrun`、上下文并行、FP8/INT8、FlashAttention 3及可混合的DMD/OPSD LoRA运行。
- **作品 / 场景：**长课件讲师、虚拟主播、播客视频化、多角色访谈和预生成互动电影分支。
- **成熟度：**已开源；尚非实时数字人，也没有公开P95生成延迟和并发数据。
- **证据级别：**代码与权重可验证；33,051票、Elo 1068.1及“六系统第二名”为作者评测。
- **重要性 / 阅读：**高 / 必读。

### 2. PAN 2：语言规划与视频世界模拟形成可编程开源栈

- **类型 / 日期 / 主线：**世界模型、训练代码、权重、agent skill；11 月 10 日发布，11 月 11 日 MBZUAI 公告。
- **官方链接：**[技术博客](https://ifm.ai/blog/pan2/)、[GitHub](https://github.com/ifm-ai/PAN2)、[模型卡](https://huggingface.co/IFM/PAN2)、[公告](https://ifm.ai/pan2/press-release/)。
- **相对上期：**窗口边界漏报，今日补录。
- **核心贡献：**概念推理器先产生包含主体、时序事件和相机运动的结构化世界状态；29B MMDiT再生成最长20秒的视频latent，Wan 2.2 VAE负责解码。作者消融中，移除概念推理后完整计划成功率由34.0%降至0。
- **Coding接口：**提供训练、SFT、断点恢复、Diffusers、vLLM、JSON prompt及面向Codex/Claude Code的Conceptual Reasoner skill。
- **作品 / 场景：**机器人行动预演、互动叙事分支预可视化、物理教学、广告动作验证和agent训练数据生成。
- **成熟度：**已开源、可自托管；29B模型和H200导向的配置使复现成本较高。
- **证据级别：**作者实验。75.1%步骤完成率、34.0%完整计划完成率来自自建评测；VLM judge虽采用多次怀疑性复核，仍不是物理引擎真值。
- **重要性 / 阅读：**高 / 必读。

### 3. Haru-4B：可本地运行的全双工角色语音底座

- **类型 / 日期 / 主线：**模型、权重、GitHub；11 月 13 日；数字人基础设施。
- **官方链接：**[技术博客](https://blog.higurashi.ai/melte/haru4b/)、[模型卡](https://huggingface.co/higurashi-ai/Haru-4B)、[项目页](https://www.higurashi.ai/haru4b/)。
- **相对上期：**首次收录。
- **核心贡献：**把用户音频、模型音频和文本以7.5 Hz同步输入同一语言模型；每133毫秒处理一个64维连续音频latent，MeanFlow音频头只需一步采样。系统能学习相觅、重叠说话、打断和何时继续发言。
- **Coding接口：**约12 GB显存即可运行PyTorch服务；另有MLX macOS应用、vLLM-Omni插件和逐帧`DuplexSession.step()`接口。
- **作品 / 场景：**可打断数字员工、语言陪练、游戏无线电角色、实时虚拟主播大脑及具身机器人语音层。
- **成熟度：**Apache-2.0开源研究底座。项目方测得M1 Max内部处理P50约65毫秒，但另有最高133毫秒音频分帧延迟，且未给出完整首响应延迟和独立benchmark。
- **证据级别：**官方测量＋可运行代码；模型卡明确它不是可靠事实源或指令助手。
- **重要性 / 阅读：**高 / 必读。

### 4. CloudRobo-WM1.2：世界预测和动作生成进入昇腾机器人平台

- **类型 / 日期 / 主线：**模型发布、机器人平台；11 月 16 日；世界模型/工业应用。
- **官方链接：**[华为云发布会页面](https://www.huaweicloud.com/about/live/261116.html)、[RoboTwin 2.0规则与榜单](https://robotwin-platform.github.io/leaderboard)、[现有CloudRobo-WM适配代码](https://github.com/XPolicyLab/XPolicyLab/blob/main/policy/CloudRobo_WM/README.md)。
- **相对上期：**11 月 16 日日报截稿后新增。
- **核心贡献：**官方发布议程确认CloudRobo-WM1.2及“正式发布暨开源”。公开报道描述其包含PPA多模态世界表示、DualAct动作架构、多粒度预训练和跨机器人本体运动建模。
- **Coding接口：**现有XPolicyLab适配层公开了三路RGB＋Joint14输入、四步推理、32步重规划、训练/部署脚本和benchmark adapter；但这些资源标注为CloudRobo-WM，不足以证明等同1.2完整发布。
- **作品 / 场景：**机器人操作、清扫机器人、仿真训练和跨本体策略迁移。
- **成熟度：**正式发布；精确1.2资源待核验，不能标为已完整开源。RoboTwin 88.98%可在榜单生态中交叉核验，LIBERO-Pro 81.7%目前主要是官方声称。
- **证据级别：**官方发布＋公开benchmark；真实机器人和产业采用主要为官方声称。
- **重要性 / 阅读：**高 / 必读。

## 4. 数字人 / 虚拟形象能力进展

- **生成与驱动：**LongCat 1.6把语音、参考图、文本和续写统一为可脚本化管线，并支持双人音频。核心增量是长期稳定性，不是新的3D身体控制。
- **3D/4D表示：**本周期暂无高质量新3D/4D Gaussian人体、mesh数字人或单图可动画3D头像发布。
- **实时交互：**Haru-4B补齐“边听边说”的语音脑；LongCat仍需离线生成。把二者直接串联不会自动得到实时视频数字人，因为视频端没有逐133毫秒消费音频的流式接口。
- **音视频与情感：**Haru保留语气和说话时机，并能以角色卡及参考声音控制人物；LongCat负责将成段音频转为口型、面部、头部和身体动作。两者都缺独立情感准确性评测。
- **工程部署：**Haru约12 GB显存即可启动，适合本地交互原型；LongCat包含INT8、FP8和多GPU路径，但仍偏数据中心批处理。
- **安全与身份治理：**Haru模型卡要求仅使用有权使用的参考声音；LongCat未提供完整肖像授权、声音授权撤销、水印或人物溯源流程。本周期没有新的身份治理技术。

能较快进入产品的是全双工语音角色和预生成长视频讲师；实时全身数字人、多主体视频通话和长时视觉陪伴仍处于组合研发阶段。

## 5. 世界模型进展

PAN 2进一步确立了“双状态”架构：语言模型维护可读的概念状态，扩散模型生成感知状态。它比单纯长prompt更适合代码审计，因为事件主体、时间范围和相机运动可以落到JSON；但这些状态仍是模型推断，不是游戏引擎或物理模拟器真值。

PAN 2的评测结果也给出明确上限：单步完成率75.1%，完整计划只有34.0%，说明错误仍会沿步骤快速累积。它适合做候选行动的低成本视觉预演，不适合单独承担安全控制。

CloudRobo-WM1.2则把世界模型从“生成未来视频”推向“直接生成机器人动作”。这条路线更接近工业价值，但必须区分模拟榜单、真实机器人验证和规模部署；当前证据主要停留在公开benchmark与发布会。

本周期没有新的可实时游玩的通用视频世界模型，也没有新的多人状态一致性、长时间回访或物理守恒独立评测。

## 6. Coding × 新型互动作品

### 链路一：可打断的本地数字角色

**麦克风音频 → Haru逐133毫秒同步听说 → 角色状态机/工具调用 → 音频与文本事件 → 2D/3D头像运行时**

代码负责角色记忆、权限、业务事实和工具调用；Haru负责说话时机、相觅及声音表现；头像引擎负责口型和渲染。Haru语音层已有可运行证据，完整视频数字人属于组合推断。

### 链路二：长时虚拟讲师与节目主持

**课程脚本／对话音轨 → TTS或真人录音 → LongCat 1.6 JSON任务 → 分段生成与续写 → 自动质检 → NLE人工终审**

模型负责长时口型和肢体表演；代码负责切段、参考帧、失败重试、漂移检测和字幕；传统后期系统负责最终时间线。代码和权重可运行，但十分钟稳定性需独立验证。

### 链路三：agent先模拟、再决定

**agent生成多个候选计划 → PAN 2 Conceptual Reasoner编译成结构化事件 → 世界模型生成结果视频 → VLM/规则评分 → 选择计划或请求人工确认**

代码负责候选管理、预算、评分和回退；PAN 2负责预测可视后果；真实执行器只接收通过门禁的行动。可用于低风险预演，不能取代真实物理验证。

### 链路四：机器人世界—动作联合运行时

**多相机与关节状态 → CloudRobo世界表示 → DualAct候选动作 → XPolicyLab标准接口 → 仿真/真机控制器 → 状态反馈**

世界模型负责预测与动作生成，控制器负责限速、碰撞边界和急停，代码负责设备适配、日志和回滚。现有CloudRobo适配可读，但精确1.2复现路径仍待官方仓库。

### 链路五：互动叙事的“草稿模拟器”

**剧情状态机 → 代码生成事件JSON → PAN 2生成20秒视觉预演 → 人工或自动检查因果顺序 → LongCat生成角色对白表演 → Unreal/网页运行**

代码保存任务、库存和分支真值；PAN 2验证场景后果；LongCat生成长镜头表演；传统引擎处理交互。各组件分别可运行，端到端作品属于本报告推断。

## 9. 系统架构与技术趋势判断

明显升温的方向有三个：长视频数字人中的误差恢复、全双工语音中的同步多流、世界模型中的显式概念状态。单纯扩大上下文或提高画质正在让位于可读、可检查、可恢复的运行时状态。

正在形成的复用架构是：

**权威业务/物理状态 → coding agent生成结构化事件 → 世界模型预演 → 语音与角色模型表演 → 引擎/控制器执行 → 自动验收与回退。**

其中，代码负责对象ID、权限、事件顺序、预算、网络同步和安全门禁；生成模型负责开放式语言、声音、动作细节和视觉补全；传统引擎或机器人控制器负责碰撞、状态真值、实时调度和急停。

关键未解问题包括：长视频独立评测、实时视频端到端延迟、多人状态同步、世界模型结构化状态的可查询性、真实机器人闭环成功率、声音与肖像授权、失败恢复以及模型judge偏差。

需要降级处理的说法包括：把LongCat“十分钟演示”写成十分钟无漂移保证；把Haru的65毫秒内部处理时间写成65毫秒首响应；把PAN 2称为物理模拟器；把CloudRobo-WM1.2称为已完整可下载开源；把RoboTwin成绩直接外推到真实机器人规模部署。

## 11. 下周跟踪与可行动建议

需要持续追踪：

1. CloudRobo-WM1.2是否公布精确仓库、权重哈希、许可证和1.0→1.2版本映射。
2. RoboTwin 88.98%能否由公开训练及部署脚本复现。

4. LongCat INT8/FP8对嘴部细节及人物身份的质量损失。
5. Haru在真实噪声、多人同时说话和网络抖动下的打断恢复率。
6. Haru是否出现instruction-tuned版本及工具调用接口。
7. PAN 2在外部benchmark上的物理一致性和候选计划排序相关性。
8. PAN 2是否能输出可查询实体状态，而不只输出结构化提示和视频。

本周建议小实验：

1. **五分钟长视频压力测试。**目标：验证LongCat 1.6的实际误差累积。组件：固定参考图、五分钟中英双语音频、1.5与1.6权重。难点：公平推理配置和漂移量化。成功判据：每30秒的人脸相似度、口型误差和背景变化均有曲线，1.6显著优于1.5。
2. **全双工数字员工原型。**目标：测试边听边说和人工打断。组件：Haru、简单工具调用路由、WebRTC和静态/3D头像。难点：避免基础模型编造业务事实。成功判据：20次插话中至少18次能停止或修正回复，所有业务答案来自受控工具。
3. **世界模型候选计划排序。**目标：判断PAN 2视频能否帮助agent选对行动。组件：PAN 2 skill、三个候选计划、VLM评分器和简单规则环境。难点：生成随机性与judge偏差。成功判据：固定20个任务中，使用PAN 2预演后的选择成功率显著高于仅靠语言规划。
4. **预测—执行差异日志。**目标：为未来CloudRobo或其他WAM建立可观测性模板。组件：仿真器、动作序列、预测视频、真实状态和事件日志。难点：视觉帧与结构化状态对齐。成功判据：每次失败能定位为感知、世界预测、动作生成、控制器或执行环境中的一个明确层级。
