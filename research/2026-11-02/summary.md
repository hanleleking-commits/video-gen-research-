# 数字人、世界模型与互动作品研究日报：2026-11-02

检索窗口：2026-10-27 至 2026-11-02。  
信息截点：2026-11-02 09:30（Asia/Shanghai）。已与 10 月 27 日至 11 月 1 日日报去重；由于截点早于欧美工作日，今日新增主要来自项目状态更新，以及对窗口内遗漏论文的补充核验。

## 1. 本日摘要

本周期最清晰的趋势，是世界模型正在从“输入动作、输出视频”转向“代码维护权威状态，结构化代理约束画面，生成模型负责视觉呈现”的混合运行时。

此前日报漏收的 Wizard 是这一趋势的重要证据：它用骨骼、场景几何和战斗状态构成显式世界状态，再由 Wan2.2 渲染，官方项目页声称达到 24 FPS；但代码尚未发布，不能独立复现。

GROME则从另一侧补齐长时运行问题：把静态场景与动态实体记忆分开，在不训练基础模型的情况下，通过原生条件通道注入局部历史和实体最新状态。其价值更像可插拔运行时记忆，而非新的基础视频模型。

Hy‑Nomas在10月31日新增图像初始化入口，使“上传世界参考图—文本修改—相机探索”的完整交互链路进入官方在线demo；这是相对上期最实质的产品状态变化。

数字人方向本日没有新的高质量语音驱动头像或全双工对话模型。窗口内仍以HairDeck的可动画发型资产和ReferStream的运行中角色注入最值得跟踪，但前者是离线资产工具，后者仍未开放推理代码。

Coding侧出现两个互补信号：Gym‑Anything让coding agent直接创建并审计物理仿真；Algebraic World Model进一步把观察到的游戏规则编译为Python模型和Lean证明，说明“世界状态必须可执行、可测试、可证明”正在成为研究方向。

HyperFrames 11月1日连续更新了宿主快捷键、媒体路径、缓存目录、预览恢复和大媒体卸载接口，显示coding agent驱动的视频作品开始补齐工程可靠性，但它目前是离线/云端视频制作框架，不是实时互动世界运行时。

工业成熟度仍未发生跃迁：本周期最强证据仍是可运行研究demo和开源组件，没有新增客户试点、生产SLA、P95延迟、并发或单位会话成本数据。

## 3. 最值得关注的 11 个进展

### 1. Wizard：显式游戏状态驱动24 FPS生成世界

- **类型 / 日期 / 主线：**论文、demo；2026-10-29；世界模型、Coding。
- **官方链接：**[论文](https://arxiv.org/abs/2610.40339)、[项目页](https://wyzardwu.github.io/wizard/)。
- **相对上期：**窗口内遗漏，今日补收。
- **核心贡献：**骨骼描述角色、几何描述场景、状态机维护位置、血量、动作阶段和冷却；OpenGL把状态编译为视觉代理，Wan2.2‑TI2V‑5B以两步去噪渲染。官方报告数据覆盖750个场景、178个角色、50.3小时代理—视频对。
- **Coding接口：**Qwen3‑VL‑8B把文本指令转成几何操作程序；规则控制器处理命中和伤害；键盘、文字或图像均可触发世界修改。
- **场景：**可编程Boss战、角色换装与变形、UGC游戏、互动电影。
- **成熟度 / 证据：**论文demo；24 FPS为官方声称，代码标记“soon”。
- **重要性 / 阅读：**高 / 必读。

### 2. GROME：静态与动态分解的免训练世界记忆

- **类型 / 日期 / 主线：**论文、运行时方法；2026-10-29；世界模型。
- **官方链接：**[论文](https://arxiv.org/abs/2610.39812)。
- **相对上期：**窗口内遗漏，今日补收。
- **核心贡献：**静态记忆保存局部空间历史，动态记忆保存实体最新状态；按当前位置检索后，通过基础模型原有条件通道注入，无需重新训练骨干。
- **Coding接口：**可封装为按会话ID管理的`update/query/inject`记忆服务，允许引擎或外部传感器写入观察。
- **场景：**可重访世界、长期NPC、机器人视觉记忆、持续虚拟空间。
- **成熟度 / 证据：**论文实测；未确认公开代码和独立复现。
- **重要性 / 阅读：**高 / 必读。

### 3. Hy‑Nomas：官方demo新增图像初始化

### 4. Fight World Model：规则执行与视觉渲染分层

## 5. 世界模型进展

- **架构与训练：**Wizard和Fight WM均将规则执行与画面生成分离；GROME与L3G分别采用分解记忆和潜在3D记忆。
- **可控/可玩生成：**控制信号从相机和文本扩展到骨骼、几何程序、战斗状态和interaction proxy。
- **长时与物理一致性：**记忆系统正在从堆叠历史帧转向实体状态、局部空间历史和可提交的显式状态。
- **空间表示：**骨骼、深度、mesh、OpenGL代理、3D Gaussian latent正在成为代码与视频模型之间的协议层。
- **机器人/游戏/仿真：**Gym‑Anything把世界创建变为软件工程任务；AWM则进一步要求规则能够被形式化验证。
- **实时部署与评测：**Wizard的24 FPS和L3G的9 FPS均只有作者证据；WorldProbe代码不可访问，独立复测仍受阻。

## 6. Coding × 新型互动作品

### 链路一：玩家可编程的生成式Boss战

**文本/按键 → agent编写几何操作或选择动作 → 权威战斗状态机 → 骨骼/几何代理 → Wizard视频渲染**

代码负责血量、冷却、命中和世界变换；模型负责视觉风格与运动细节。已有24 FPS作者demo，代码未开放。

### 链路二：规则可修改的生成式格斗

**玩家输入 → Fight WM规则引擎 → interaction proxy → 身份绑定视频生成 → 客户端播放**

设计师可修改伤害、免疫和吸血，不必重训模型。已有论文demo，尚无网络同步或服务成本证据。

### 链路三：从参考图启动的持续世界

**用户图片 → Hy‑Nomas世界初始化 → 文本事件/相机控制 → WebSocket会话 → 浏览器播放**

代码维护会话、存档、权限、历史长度和GPU预算；模型生成观察画面。官方demo与开源接口已存在，生产P95未知。

### 链路四：带分解记忆的长期NPC世界

**当前观察 → GROME静态/动态记忆写入 → 局部检索 → 基础视频模型 → 下一观察**

静态场景和动态角色分别保存，可避免把完整视频历史塞回上下文。方法有论文证据；完整NPC系统属于本报告推断。

### 链路五：可验证的程序化关卡

**agent探索关卡 → Python规则假设 → 自动回放测试 → Lean形式化 → 证明可达或不可达**

代码负责世界规则和证明，生成模型可负责外观与动画，传统引擎负责权威执行。AWM已验证规则发现链路，与视频渲染整合属于本报告推断。

### 链路六：coding agent生产机器人训练世界

**任务规范 → 创建agent写仿真 → 审计agent破坏测试 → RL环境 → VLA训练**

物理引擎维护真实动力学，agent生成并修复代码，模型策略在环境中学习。Gym‑Anything已开放环境，但0%测试成功率说明自动质量控制仍是核心瓶颈。

## 9. 系统架构与技术趋势判断

明显升温的是“权威代码状态＋结构化视觉代理＋生成式渲染”。骨骼、几何、深度、实体状态和interaction proxy正在取代纯文本提示，成为模型与传统引擎之间的中间协议。

第二个趋势是上下文工程视频化：静态/动态分解、潜在3D记忆、局部检索、缓存临时覆盖与恢复，正在形成独立的世界模型运行时层。

第三个趋势是可执行验收。世界不能只看起来合理，还需要经过碰撞检测、状态回放、任务成功率、对抗审计，甚至形式化证明。

数字人方向则出现断层：资产生成和角色动态注入在进步，但实时听说、情感、视线、打断和生产级RTC没有同步新增。

关键未解问题包括：低于100毫秒的输入反馈、多会话并发、多人权威状态、长时角色身份、故障恢复、输出审核、授权凭证和单位会话成本。

应降级看待：把Wizard的24 FPS直接等同于端到端玩家延迟；在代码发布前接受L3G的9 FPS；把ReferStream网页仓库称为开源实现；把HyperFrames的视频渲染能力解释为实时互动世界。

## 10. 论文精读候选

1. [Wizard](https://arxiv.org/abs/2610.40339)：重点读代理表示、角色自适应mask、因果蒸馏和24 FPS计时口径。差异是把场景编辑、角色动画和战斗规则统一到显式状态；风险是无代码。
2. [GROME](https://arxiv.org/abs/2610.39812)：重点读静态/动态分解、空间对齐检索和免训练注入。风险是动态实体关联错误可能累积。
3. [Fight World Model](https://arxiv.org/abs/2610.40607)：重点读interaction proxy、身份绑定和规则干预实验。风险是封闭格斗域。
4. [Algebraic World Model](https://arxiv.org/abs/2610.40503)：重点读Python假设修订、类型化规则与Lean转换。价值在于为生成世界增加可验证规则层；风险是难以扩展到连续视觉世界。
5. [WorldProbe](https://arxiv.org/abs/2610.39721)：重点读主动探索agent、四类probe及长时退化指标。风险是仓库不可访问、部分评价依赖模型裁判。

## 11. 下周跟踪与可行动建议

持续跟踪：

1. Wizard是否发布代码、权重、硬件配置和端到端输入延迟。
2. GROME是否开放实现，以及能否接入Hy‑Nomas或其他开放世界模型。
3. Hy‑Nomas图像初始化后的首帧延迟、连续帧率、显存和多会话并发。
4. L3G‑World四项release plan是否有任何实际产物上线。
5. WorldProbe仓库是否恢复，并加入Wizard、Hy‑Nomas、L3G等最新模型。
6. ReferStream是否发布推理代码和角色注入时延。
7. HairDeck导出的VRM在Unity、Godot和Web运行时中的骨链稳定性。
8. HyperFrames能否形成“agent生成—自动检查—局部重渲染—发布”的可观测生产闭环。

本周可执行实验：

1. **参考图世界交互测试**：用Hy‑Nomas创建同一场景的三轮事件和相机控制；难点是记录真实首帧与指令生效时间；成功判据是角色、物体和背景在三轮后仍可辨认且旧动作不重复。
2. **VRM发型资产测试**：HairDeck生成四个发型并导入Unity或Godot；难点是穿模、UV和骨链参数；成功判据是60秒头部运动无明显脱落、爆炸或严重穿模。
3. **规则—代理—渲染最小原型**：不用训练模型，以Godot/Three.js维护血量和技能状态，输出骨骼/深度代理，再调用现有I2V模型离线渲染；成功判据是修改伤害规则时无需改生成提示或模型。
4. **世界模型回归CI**：实现简化版WorldProbe“前进—转向—离开—返回”脚本，保存输入事件、输出帧和实体一致性指标；成功判据是模型版本升级后能自动定位首次身份、几何或状态失效时间。
