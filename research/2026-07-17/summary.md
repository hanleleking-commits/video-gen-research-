# 数字人、世界模型与互动作品研究日报：2026-07-17

检索窗口：2026-07-11 至 2026-07-17。  
日期说明：本期核心新增主要来自 7 月 15 日提交、7 月 16 日公开的 arXiv 批次；已与 7 月 13—16 日日报去重。WanToFight、FlowWAM、Seriality Gap、Hy-Embodied、Jetson-PI 等无实质更新，不重复计入。

## 1. 本日摘要

本日最重要的变化不是又出现一个更逼真的可玩视频 demo，而是世界模型开始正面处理“画面背后谁保存游戏状态”这一核心问题。From Pixels to States明确提出，应以传统引擎的 action—state—observation 循环重构互动世界模型，并提供包含动作、真实游戏状态和画面的《黑神话：悟空》90 小时数据引擎。M⁴World则把驾驶世界模型推进到多视角视频与 LiDAR 同步、对象级布局和外观编辑、分钟级流式生成，但代码和运行成本尚未公开。Coding侧最强工程新增是REAL：它已开放仿真环境、MCP工具、程序化任务生成、SFT代码和部分数据，机器人通过结构化工具进行探索、询问、抓取和开关门，形成了本周期最完整的“agent—运行时—真实执行”链路。数字人方向没有新的实时 talking-head或统一脸手身语音系统，新增集中在可解释舞蹈动作、4K多视角动捕、服装编辑和视频身份保护。Atomic Movements把舞蹈拆成可编排的动作单元，为时间线、状态机和人工编辑提供了比连续motion latent更清晰的接口。TC-UAP及LifeGenIP竞赛则说明，数字人产业的身份治理正在从检测生成结果前移到“阻止公开视频被参考生成或LoRA定制”。整体上，研究重点正由纯像素生成转向显式状态、结构化工具、可编辑对象、物理资产和自动验收；但除REAL外，多数新增仍只有作者实验或占位仓库，尚不能视为可部署产品。

## 3. 最值得关注的 10 个进展

### 1. From Pixels to States：把互动世界模型重新定义为状态化游戏引擎

- **类型 / 时间 / 主线：** 观点与技术综述、数据引擎；2026-07-15提交；世界模型、Coding。
- **官方链接：** [论文](https://arxiv.org/abs/2607.14076)。
- **相对上期的新变化：** 全新条目；直接回应WanToFight等系统只有生成画面、缺少可查询权威状态的问题。
- **核心贡献：** 以玩家动作、游戏状态、观察画面的循环分析动作控制、状态演化、持久性和实时生成；构建超过90小时的《黑神话：悟空》数据，包含帧对齐动作、真实游戏状态、画面及结构化语义标注。
- **Coding接口：** 状态变量、动作日志和观察帧可形成模型训练schema，也可用于服务器状态回放与回归测试；公开下载入口尚未确认。
- **场景：** 生成式游戏、互动电影、世界模型验收和状态预测。
- **成熟度 / 证据 / 重要性：** 数据引擎与研究框架；作者材料；高、必读。

### 2. M⁴World：对象可编辑、视频与LiDAR同步的分钟级驾驶世界模型

- **类型 / 时间 / 主线：** 论文、模型；2026-07-15提交；世界模型、驾驶仿真。
- **官方链接：** [论文](https://arxiv.org/abs/2607.14005)。
- **相对上期的新变化：** 全新条目；比OpenLongTail的缺失视角补全更进一步，支持对象级交互编辑和因果流式生成。
- **核心贡献：** 同步生成环视视频与LiDAR；通过条件接口修改单个对象的位置布局和外观；四步去噪进行在线因果生成，并报告分钟级稳定流式输出。
- **Coding接口：** 可由场景脚本提交对象布局、视觉参考和长尾条件，输出多传感器序列供感知、规划及闭环测试消费；代码和API未公开。
- **场景：** 驾驶长尾数据、传感器一致性测试、事故场景编辑。
- **成熟度 / 证据 / 重要性：** 研究原型；论文作者实验；高、必读。

### 3. REAL：开放MCP工具的可探索、可沟通移动机器人agent

- **类型 / 时间 / 主线：** 论文、GitHub、dataset、MCP运行时、实机案例；数据于2026-07-15开放。
- **官方链接：** [论文](https://arxiv.org/abs/2607.13653)、[GitHub](https://github.com/InternRobotics/REAL)。
- **相对上期的新变化：** 全新纳入；相较上期“契约驱动行为树”论文，REAL已提供MCP server、工具实现、仿真配置、训练入口和数据。
- **核心贡献：** agent仅使用RGB观察主动探索，可调用`navigate_to`、`find_objects`、`pick`、`place`、`open/close`、`ask`等工具；每次调用返回图像和结构化文本。
- **关键结果：** 作者报告REAL-Bench含241项任务，交互任务成功率56.9%；双臂移动机器人60次真实实验成功率78.3%。
- **Coding接口：** MCP、Python、InternUtopia/Isaac Sim、Qwen3-VL SFT、独立在线GRPO分支。
- **成熟度 / 证据 / 重要性：** 已开源研究运行时及数据、模型checkpoint待发布；作者仿真与实机实验；高、必读。

### 4. WANDA：从一次真实演示扩增开放世界移动操作数据

- **类型 / 时间 / 主线：** 论文、synthetic data engine；2026-07-14提交；世界模型、机器人。
- **官方链接：** [论文](https://arxiv.org/abs/2607.13154)。
- **相对上期的新变化：** 全新条目。
- **核心贡献：** 从RGB-D重建Gaussian背景和人机交互轨迹，重新排列接触片段，通过全身运动规划拼接新轨迹，并在照片生成的不同3D世界中合成观察。
- **Coding接口：** 重建器、接触片段库、运动规划器、状态扩增器和渲染器构成离线数据流水线。
- **场景：** 低成本机器人示教扩增、跨场景和跨机器人形态训练。
- **成熟度 / 证据 / 重要性：** 论文原型；作者仿真与实机结果，未确认代码；高、可读。

### 5. ThinkBLOX：以JSON状态和逐步推理生成可编辑3D室内场景

- **类型 / 时间 / 主线：** 论文、dataset、3D场景生成；2026-07-15提交；Coding × 互动作品。
- **官方链接：** [论文](https://arxiv.org/abs/2607.13539)。
- **相对上期的新变化：** 全新条目；将一次性场景生成改为可增量修改的状态—动作过程。
- **核心贡献：** 使用224,757组多视图场景、推理文本和结构化JSON布局训练VLM；逐个放置、移动或重排对象，并以分层奖励分别约束物理有效性、语义合理性和推理一致性。
- **Coding接口：** JSON布局是直接可脚本化的中间表示，可转换为Unity、Unreal、Godot或机器人仿真的实体生成命令。
- **场景：** 互动关卡、培训空间、室内仿真和自然语言场景编辑。
- **成熟度 / 证据 / 重要性：** 研究原型；论文作者实验；高、必读。

### 6. Atomic Movements：将音乐舞蹈变为可编排动作词表

- **类型 / 时间 / 主线：** 论文、动作生成；2026-07-15提交；数字人。
- **官方链接：** [论文](https://arxiv.org/abs/2607.13978)。
- **相对上期的新变化：** 全新条目；相较Wan-Dancer直接生成长视频，本方法输出更适合代码编辑的结构化动作计划。
- **核心贡献：** 将舞蹈数据分段聚类为原子动作，再由LLM进行语义标注；第一阶段预测动作类型、持续时间和时点，第二阶段生成平滑过渡。
- **Coding接口：** 原子动作序列可映射到时间线、行为树、骨骼动画片段或实时引擎状态机。
- **场景：** 虚拟偶像编舞、节奏游戏、舞蹈教学、互动舞台。
- **成熟度 / 证据 / 重要性：** 研究原型，未确认代码；作者实验；中高、必读。

### 7. Human4K：600万张4K多视角全身动捕数据

- **类型 / 时间 / 主线：** dataset、论文；2026-07-15提交；数字人、3D重建。
- **官方链接：** [论文](https://arxiv.org/abs/2607.13646)。
- **相对上期的新变化：** 全新条目。
- **核心贡献：** 八机位4K相机与Vicon同步，覆盖11名受试者和复杂自遮挡动作，提供高精度SMPL-X标注；作者报告对手、脚和深度歧义肢体改善尤其明显。
- **Coding接口：** 可用于训练全身mesh恢复、动作重定向、质量验收和虚拟制作捕捉模型。
- **场景：** 数字演员、体育动作、全身NPC和虚拟试衣。
- **成熟度 / 证据 / 重要性：** 数据集论文；下载与许可入口尚未确认；中高、可读。

### 8. TC-UAP / LifeGenIP：面向视频身份定制的主动保护

- **类型 / 时间 / 主线：** 论文、benchmark、竞赛starting kit；2026-07-14提交；数字人安全。
- **官方链接：** [论文](https://arxiv.org/abs/2607.13336)、[Apache-2.0 starting kit](https://github.com/tmllab/ECCV26_LifeGenIP_starting_kit)。
- **相对上期的新变化：** 本周期新增的身份治理代表。
- **核心贡献：** 对同一身份的多段视频学习时间一致通用扰动，抵抗单帧I2V参考、视频LoRA微调以及时间平均等攻击；竞赛分别评估有效性、鲁棒性和跨模型迁移。
- **Coding接口：** starting kit包含Python评测管线和Codabench入口，可加入数字人资产发布前的保护测试。
- **场景：** 演员样片、主播素材、企业数字员工原始视频的反滥用保护。
- **成熟度 / 证据 / 重要性：** 研究防御与公开评测工具；作者实验，实际平台兼容性待验证；中高、必读。

### 9. VideoRAE：用视频理解表征替代纯像素VAE latent

- **类型 / 时间 / 主线：** 论文、video tokenizer；2026-07-15提交；支撑基础设施。
- **官方链接：** [论文](https://arxiv.org/abs/2607.14088)、[项目页](https://zhxie0117.github.io/VideoRAE/)。
- **相对上期的新变化：** 全新条目。
- **核心贡献：** 从冻结V-JEPA 2、VideoMAEv2式编码器提取多尺度特征，压缩为DiT连续latent或自回归离散token；作者报告相对自编码器基线约快5倍收敛。
- **Coding接口：** 理论上可替换视频模型的VAE/tokenizer层，使世界模型latent同时保留较强语义与时空结构。
- **成熟度 / 证据 / 重要性：** 论文与占位GitHub，代码标记“Coming soon”；作者实验；中高、必读。

## 4. 数字人 / 虚拟形象能力进展

**生成与驱动。** 本周期没有新的speech-driven avatar、lip-sync或可打断会话系统。Atomic Movements改善的是骨骼舞蹈的结构和可控性，不生成口型、视线或对话情绪。

**3D/4D表示。** Human4K补充高分辨率全身SMPL-X监督；[T3HG-Editor](https://arxiv.org/abs/2607.13654)利用SMPL-X顶点对应和SDF约束进行多视角一致服装编辑。后者能修改Gaussian人体资产，但没有证明输出可直接导入商用引擎。

**实时交互。** 今日无端到端实时数字人新增。动作词表可以进入实时状态机，但模型规划和运动补全的延迟未披露。

**音视频与情感。** 没有新的原生语音—表情—手势统一模型。舞蹈新增以音乐节奏和动作语义为中心，不应外推为虚拟客服或主播能力。

**工程部署。** 当前最可落地的是将Atomic Movements作为离线编舞器、Human4K作为训练/验收数据、T3HG-Editor作为服装资产编辑器；完整数字人仍需骨骼、blendshape、TTS、RTC和传统渲染引擎组合。

**安全与身份治理。** TC-UAP把治理前移至训练和参考输入阶段，但对压缩、转码、裁剪及不同商业模型的真实迁移效果仍需第三方验证。该方法也不能替代授权合同、水印、内容溯源与下架流程。

## 5. 世界模型进展

**架构与训练。** VideoRAE反映出视频latent正在从“可重建像素”转向“可表达语义和时空结构”；M⁴World用四步去噪支持因果流式生成。

**可控/可玩生成。** 本期的关键新增是控制粒度从按键或相机移动扩大到对象布局、对象外观和显式游戏状态。前者由M⁴World验证，后者由From Pixels to States提出数据基础。

**长时与物理一致性。** 分钟级视频连续不等于状态正确。对象是否已被拾取、敌人是否死亡、库存是否扣减，应由显式状态或传统引擎保存，不能只从像素历史推断。

**空间表示。** ThinkBLOX的JSON布局、WANDA的Gaussian世界、UniPhysGen的关节与物理属性分别承担场景状态、视觉外观和物理执行接口。

**机器人/游戏/仿真。** REAL和WANDA构成互补路线：REAL强调在线工具调用和交互澄清，WANDA强调从一次演示生成大量训练世界。

**实时部署与评测。** 本期没有新的公开世界模型端到端FPS。M⁴World只披露四步生成和分钟级输出，不应解读为实时帧率。新增[VGIF-Score](https://arxiv.org/abs/2607.13527)可把复杂提示解析为时空DAG，但其仓库仍处于待逐步发布状态。

## 6. Coding × 新型互动作品

1. **玩家输入 → 权威状态服务器 → 视频世界模型渲染 → 生成式游戏**  
   代码保存角色HP、库存、碰撞、任务和多人同步；世界模型根据动作与状态生成观察；传统引擎负责规则及回退渲染。From Pixels to States提供数据框架，完整产品实现仍属本报告推断。

2. **对象编辑脚本 → M⁴World → 环视视频与LiDAR → 驾驶长尾仿真**  
   测试代码指定车辆位置、类别和外观；模型补全多视角未来；仿真平台比较感知与规划结果。论文有作者实验，API、并发和闭环部署未公开。

3. **自然语言任务 → REAL MCP工具 → RGB反馈与结构化状态 → 机器人/NPC执行**  
   agent负责选择`navigate`、`ask`、`pick`等工具；MCP server执行并返回观察；仿真或机器人控制器承担运动与安全。该链路已有开放代码、仿真数据和实机论文证据，也可迁移为互动展览NPC，但游戏迁移属于推断。

4. **音乐 → 原子动作计划 → 动画状态机 → 可编辑虚拟偶像表演**  
   模型选择动作类型、时长和时点；代码处理节拍、动作片段、镜头与碰撞；引擎实时混合骨骼动画。动作计划有论文证据，实时引擎集成尚未公开。

5. **自然语言房间需求 → ThinkBLOX JSON增量布局 → Unity/Unreal实体 → 培训或互动空间**  
   VLM逐步添加和移动对象；代码校验JSON、碰撞、通行区域与资产ID；物理引擎负责可执行性。论文证明增量编辑，商用引擎插件属本报告推断。

6. **一次机器人演示 → WANDA轨迹和世界扩增 → policy训练 → 跨场景部署**  
   代码抽取接触片段、规划新轨迹并生成Gaussian背景；模型学习多样观察；真实机器人仅执行通过安全验证的policy。作者有实机证据，数据引擎代码尚未确认开放。

## 8. 可复现资源与开发者入口

- [REAL](https://github.com/InternRobotics/REAL)：MIT许可证；已含MCP server、工具、InternUtopia配置、程序化数据生成、Qwen3-VL SFT和测试。REAL-Data已开放，模型checkpoint仍为“coming soon”。最小验证是启动单场景，依次调用`list_receptacles`、`navigate_to`、`find_objects`和`pick`，检查图像与结构化反馈闭环。
- [REAL-Data入口及安装说明](https://github.com/InternRobotics/REAL)：仓库提供校验和及6,205个文件的完整性验证；还需单独获取MesaTask对象和Isaac/InternUtopia环境。值得优先复现。
- [LifeGenIP starting kit](https://github.com/tmllab/ECCV26_LifeGenIP_starting_kit)：Apache-2.0代码，但MEAD数据受单独条款约束。最小路径是对同一人脸视频比较原始、扰动、时间平均后的I2V身份相似度。
- [VideoRAE](https://github.com/zhxie0117/VideoRAE)：目前只有README，占位状态，不可复现。
- [UniPhysGen](https://github.com/breezexian/UniPhysGen)：Apache-2.0仓库目前仅许可证和README，无代码、模型或UniPhys-40K下载。
- [VGIF-Score](https://github.com/PRIS-CV/VGIF-SCORE)：目前仅README，作者称代码、benchmark和结果将逐步整理发布。
- M⁴World、ThinkBLOX、Atomic Movements、Human4K、WANDA和T3HG-Editor：未确认完整代码、权重或数据下载，不建议作为当前开发依赖。

## 9. 系统架构与技术趋势判断

明显升温的方向是显式状态世界模型、对象级编辑、MCP工具运行时、可解释动作token、物理资产自动标注和生成内容CI。单纯以画面连续性证明“可玩性”的路线正在受到更严格质疑。

正在形成的复用架构是：

- agent或玩家产生自然语言、按键或对象编辑指令；
- MCP、JSON schema或动作词表将意图转换成结构化调用；
- 权威服务器、行为树或状态机保存规则状态；
- 世界模型生成观察、候选未来和训练数据；
- Gaussian、mesh、SMPL-X和物理属性形成可查询空间层；
- Unity、Unreal、Isaac或传统控制器负责碰撞、网络同步和安全执行；
- ST-DAG、VLM judge、因果测试和身份保护工具进入发布质量门。

关键未解问题包括：像素结果可靠反写为对象状态；长时交互中的规则与物理守恒；数字人脸、手、全身、语音和视线的统一实时控制；生成运行时的并发成本；MCP工具权限与错误恢复；真实人物数据许可和可撤销授权。

需要降级看待的项目包括只提供“Coming soon”仓库的VideoRAE、仅有README的UniPhysGen和VGIF-Score，以及没有公开实际生成速度的M⁴World。它们的研究方向值得关注，但工程成熟度明显低于REAL。

## 10. 论文精读候选

1. [From Pixels to States](https://arxiv.org/abs/2607.14076)：重点读action—state—observation框架、四个能力维度和《黑神话：悟空》数据schema。价值在于为生成式游戏划定“模型与引擎”的边界；风险是数据尚未确认开放。
2. [M⁴World](https://arxiv.org/abs/2607.14005)：重点读多视角视频—LiDAR联合表示、对象控制条件、四步因果生成和少样本长尾定制。风险是无代码、无公开实际延迟。
3. [REAL](https://arxiv.org/abs/2607.13653)：重点读sim-to-real一致API、MCP工具、交互澄清、分层SFT/RL和实机实验。差异是避免oracle状态并提供真实工具运行时；风险是checkpoint未发布且环境依赖较重。
4. [ThinkBLOX](https://arxiv.org/abs/2607.13539)：重点读JSON布局表示、增量状态更新和Tier-Decoupled GDPO。差异是可局部修改而非一次性生成；风险是复杂资产和真实物理环境中的泛化。
5. [TC-UAP](https://arxiv.org/abs/2607.13336)：重点读3D VAE时间压缩对扰动的影响、身份级滑动窗口优化和时间攻击。风险是对未知商业模型、转码和社交平台处理链的迁移效果。

## 11. 下周跟踪与可行动建议

继续追踪：

1. From Pixels to States是否开放90小时数据、状态schema和采集工具。
2. M⁴World是否发布代码、对象编辑接口、显存和端到端帧延迟。
3. REAL何时开放checkpoint，以及MCP在线RL分支能否在公开数据上复现。
4. ThinkBLOX能否导出Unity、Unreal、USD或标准物理场景。
5. Atomic Movements是否开放动作词表、骨骼格式和实时生成速度。
6. Human4K的数据下载、人物授权范围及商业使用许可证。
7. UniPhysGen、VideoRAE和VGIF-Score占位仓库何时转为真实发布。
8. TC-UAP在压缩、裁剪、重采样和未知I2V模型上的第三方迁移结果。

本周可执行实验：

1. **MCP互动NPC原型。** 目标：验证REAL式工具协议能否迁移到游戏角色。组件：本地MCP server、十个场景工具、Godot或Unity状态机。难点：工具失败恢复。成功判据：50个自然语言任务中不存在的工具调用为零，状态修改均可回放。
2. **显式状态生成世界。** 目标：区分画面连续与规则正确。组件：小型游戏、状态日志、视频生成后端。难点：状态到视觉条件映射。成功判据：连续10分钟内HP、库存、对象位置和任务状态与服务器日志一致。
3. **原子舞蹈时间线。** 目标：验证结构化动作是否比连续motion更易编辑。组件：音乐节拍器、十至二十个动作片段、动画状态机。难点：动作过渡和脚滑。成功判据：替换任一八拍片段不会破坏前后节拍及角色根节点连续性。
4. **视频身份保护回归。** 目标：评估主动保护对现有I2V管线的实际作用。组件：LifeGenIP kit、经授权人脸视频、一个I2V模型、压缩与时间平均攻击。难点：平衡视觉扰动和保护强度。成功判据：授权素材肉眼质量可接受，同时在至少三类处理后显著降低身份复现率。
