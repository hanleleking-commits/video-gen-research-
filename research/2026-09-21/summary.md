# 数字人、世界模型与互动作品研究日报：2026-09-21

检索窗口：2026-09-15 至 2026-09-21。

## 1. 本日摘要

过去七天的高质量增量主要集中在 9 月 16—17 日，整体重心不是更大的通用视频模型，而是把生成能力转成可执行、可验证、可持续运行的系统。数字人方向新增较少但指向明确：VibeAvatar 将音素准确性与动作审美分开优化；KoUniTalk 则补上韩英双语 3D 口型评测；LiveKit 新增 Synthesia 插件后，实时数字人已可作为标准 RTC 参与者接入 agent 运行时。世界模型方向的主线从“生成未来 RGB”进一步分化为运动、触觉、接触、3D 点轨迹和轻量记忆等任务相关状态，降低闭环推理成本。MoWAM 甚至在部署阶段完全移除未来视频生成，说明可行动性正压倒纯视觉保真度。WorldContact、DexTouch-WM 和 ReShoot 都给出了真实机器人结果，但均仍是受限任务上的论文实测，不能等同于规模化工业部署。Coding 方向最强信号来自 SafeHarness：让模型写机器人代码并不自动带来安全性，必须由确定性的路径验证、接触约束和重规划机制包裹。综合来看，正在形成的主流架构是“生成模型提出候选状态或动作，代码运行时维护权威状态、约束、事件和回退，传统控制器完成最终执行”。本周期没有发现可信的新增长时可玩视频产品或大规模数字人客户部署，产业成熟度的实质提升主要来自运行时插件、可观测性和结构化接口。

## 3. 最值得关注的 12 个进展

### 1. SafeHarness：把 coding agent 的安全约束变成可执行程序

- **类型**：论文；**主线**：Coding × 互动作品 / 机器人。
- **官方链接与日期**：[arXiv 2609.20822](https://arxiv.org/abs/2609.20822)，2026-09-17。
- **相对上期**：9 月 18 日日报后首次收录。
- **核心贡献**：论文发现，仅在提示词中要求“不要碰障碍物”并不能使 coding agent 安全；SafeHarness 将操作拆成路径阶段和接触阶段，显式生成、验证并在必要时重规划 waypoint，同时约束接触位置。论文报告任务成功率 71.9%、无碰撞率 87.5%。
- **Coding 接口**：场景边界框、waypoint 序列、路径验证器、技能调用与冻结 VLA 共同组成 agent harness。
- **场景**：机器人编程、危险区域作业、可验证 NPC 导航、互动装置。
- **成熟度 / 证据 / 重要性 / 阅读**：研究原型；论文实测；高；必读。

### 2. MoWAM：用“未来运动”取代昂贵的未来视频

- **类型**：论文 / 世界—动作模型；**主线**：世界模型。
- **官方链接与日期**：[arXiv 2609.20709](https://arxiv.org/abs/2609.20709)，2026-09-17。
- **相对上期**：首次收录。
- **核心贡献**：训练时联合学习视频动力学、结构化未来运动和动作，推理时移除视频生成，只保留运动—动作候选及任务进度 verifier；这直接针对 WAM 视频 rollout 成本高的问题。
- **Coding 接口**：候选采样器、运动表示、任务进度评分器可嵌入机器人控制循环。
- **场景**：低延迟机械臂规划、边缘机器人、需要多候选搜索的生产操作。
- **成熟度 / 证据 / 重要性 / 阅读**：研究原型、含真实操作实验；论文实测；高；必读。

### 3. WorldContact：将可变形物体接触模拟提速并用于真实机器人

- **类型**：论文 / 数据引擎；**主线**：世界模型 / 工业仿真。
- **官方链接与日期**：[arXiv 2609.19600](https://arxiv.org/abs/2609.19600)，2026-09-17。
- **相对上期**：首次收录。
- **核心贡献**：以较大时间步预测购物袋等可变形物体的接触动力学；论文报告在单张 H100 上，状态 rollout 相对源数值模拟器快 10 倍，但该数字不含渲染和磁盘 I/O。扩充数据后，袋子提起任务单次成功率由 65% 提升至 95%。
- **Coding 接口**：作为可调用的合成轨迹生成器，输出数据再用于 VLA 微调。
- **场景**：柔性包装、布料、袋装商品、仓储分拣仿真。
- **成熟度 / 证据 / 重要性 / 阅读**：研究原型、真实机器人验证；论文实测；高；必读。

### 4. DexTouch-WM：用人类触觉扩展机器人世界模型

- **类型**：论文 / dataset / 世界模型；**主线**：世界模型。
- **官方链接与日期**：[arXiv 2609.20649](https://arxiv.org/abs/2609.20649)，2026-09-17。
- **相对上期**：首次收录。
- **核心贡献**：在人手和机器人手上使用兼容的触觉阵列，将人类动作重定向到机器人动作空间，联合预测未来 RGB 与双手触觉；固定 5 小时机器人数据、增加至 100 小时人类触觉数据后，机器人域预测得到改善。
- **Coding 接口**：动作重定向、视觉/触觉 token、合成轨迹生成和 surrogate evaluation。
- **场景**：灵巧手训练、遥操作数据采集、抓取前风险预测。
- **成熟度 / 证据 / 重要性 / 阅读**：研究原型；论文实测；高；必读。合成数据对策略收益并非所有配置都稳定，尚不能替代真实数据。

### 5. PointZero：用 3D 点轨迹完成任务预训练动力学

- **类型**：论文 / dataset / checkpoint；**主线**：世界模型 / 3D 表示。
- **官方链接与日期**：[论文](https://arxiv.org/abs/2609.19142)、[项目页](https://pointzero-wm.github.io/)，2026-09-16。
- **相对上期**：首次收录。
- **核心贡献**：以“少量已知 3D 轨迹补全全部点的未来轨迹”为预训练目标，不要求机器人动作标签；发布覆盖刚体、关节体和可变形物体的 290 万合成帧、checkpoint 和训练 recipe，并在 6/7 个仿真或真实操作任务上达到或超过基线。
- **Coding 接口**：项目提供训练与后训练路径，可把 partial tracks 替换成末端执行器位姿或增加动作头。
- **场景**：视频到机器人技能、3D 交互预测、物理资产预训练。
- **成熟度 / 证据 / 重要性 / 阅读**：已开放资源、研究原型；论文实测；高；必读。

### 6. ReShoot：生成式视频成为机器人数据管线，而非最终内容

- **类型**：论文 / 数据增强系统；**主线**：Coding × 工业应用。
- **官方链接与日期**：[arXiv 2609.19661](https://arxiv.org/abs/2609.19661)，2026-09-17。
- **相对上期**：首次收录。
- **核心贡献**：VLM 改写场景属性，边缘条件视频模型重渲染双目演示，同时原样保留动作与本体感觉标签。LIBERO-Plus 从 82.3% 提升到 85.5%；两套真实机器人在改色物体上的成功率由 0 提升到 42.9% 和 47.5%。
- **Coding 接口**：caption → 属性编辑 → 双视图生成 → 标签一致性检查 → 策略训练的自动流水线。
- **场景**：工业视觉换线、颜色/材质鲁棒性、低成本域随机化。
- **成熟度 / 证据 / 重要性 / 阅读**：研究原型、真实机器人验证；论文实测；高；必读。

### 7. JEPA-Anything：跨领域世界模型采用统一预测接口

- **类型**：论文 / GitHub / checkpoint；**主线**：世界模型基础设施。
- **官方链接与日期**：[论文](https://arxiv.org/abs/2609.20800)、[GitHub](https://github.com/Gen-Verse/JEPA-Anything)、[checkpoint 数据卡](https://huggingface.co/datasets/Gen-Verse/jepa-anything)，2026-09-17。
- **相对上期**：首次收录。
- **核心贡献**：正交预测分解把 latent state 拆成互补因素，经独立路径预测后重组；覆盖视觉、控制、分子、临床、天气等七类世界。论文报告在 Interventional Pong 上单干预误差下降 34.8%，并测试 100 步分子 rollout。
- **Coding 接口**：Python 核心库、任务设计 validator、脚手架生成器、统一 NPZ 推理入口。
- **场景**：仿真模型快速搭建、科学干预筛选、跨域预测服务。
- **成熟度 / 证据 / 重要性 / 阅读**：已开源；论文实测；高；可读。仓库目前的结构示例不能复现全部论文结果。

### 8. Workspace Models：把 VLM 历史推理蒸馏为轻量记忆 token

- **类型**：论文；**主线**：世界模型 / agent runtime。
- **官方链接与日期**：[arXiv 2609.20820](https://arxiv.org/abs/2609.20820)，2026-09-17。
- **相对上期**：首次收录。
- **核心贡献**：训练时用 VLM 标注完成任务需要的当前及历史信息，再蒸馏为可在部署期直接查询的 workspace token，避免每一步重跑 VLM 和完整历史。
- **Coding 接口**：可作为策略 observation 的 drop-in memory；适合连接状态机、事件日志和机器人策略。
- **场景**：长任务机器人、长期 NPC 记忆、低成本持续视觉 agent。
- **成熟度 / 证据 / 重要性 / 阅读**：研究原型；论文实测；中高；可读。

### 9. VibeAvatar：把发音正确与“看起来自然”分开训练

- **类型**：论文 / 数字人模型；**主线**：数字人。
- **官方链接与日期**：[arXiv 2609.18632](https://arxiv.org/abs/2609.18632)，2026-09-16。
- **相对上期**：首次收录。
- **核心贡献**：Phonetic Kinematics Adapter 负责把语音特征变成发音运动条件；Aesthetic Motion Policy 通过 GRPO 优化动作审美。论文声称约 3GB 显存可在不足 10 秒内生成 10 秒、512px 视频。
- **Coding 接口**：输入是肖像和语音，但暂未见公开 API、代码或流式事件接口。
- **场景**：本地口播、营销素材、教育讲解视频。
- **成熟度 / 证据 / 重要性 / 阅读**：研究原型；论文自报；中高；可读。速度接近离线实时，不等于可打断对话。

### 10. LiveKit Agents 1.8.2：Synthesia 数字人成为标准 agent 插件

- **类型**：SDK / GitHub / 正式产品集成；**主线**：数字人 / Coding × 互动作品。
- **官方链接与日期**：[GitHub Release](https://github.com/livekit/agents/releases)、[集成文档](https://docs.livekit.io/agents/models/avatar/plugins/synthesia/)，2026-09-15。
- **相对上期**：新增 Synthesia interactive-avatar plugin，并补充 agent 生命周期、turn handoff、interrupt 和 RPC tracing。
- **核心贡献**：一个会话可预加载最多五个数字人，并通过 `swap_avatar()` 在不中断连接的情况下切换；数字人以独立 RTC participant 发布同步音视频。
- **Coding 接口**：Python `AgentSession`、`AvatarSession`、环境变量 API key、异常类型和音频降级逻辑。
- **场景**：多角色客服、虚拟主持人、角色接力、可观测的实时数字员工。
- **成熟度 / 证据 / 重要性 / 阅读**：正式 SDK；官方文档与代码；高；必读。

### 11. Track, Articulate, Act：从普通视频生成可仿真的关节物体

- **类型**：论文 / real-to-sim 管线；**主线**：Coding × 仿真。
- **官方链接与日期**：[arXiv 2609.19119](https://arxiv.org/abs/2609.19119)、[项目页](https://track-articulate-act.github.io/)，2026-09-16。
- **核心贡献**：从单目随手拍视频提取稠密 3D 点轨迹，识别固定/运动部件、旋转或移动关节，生成 simulation-ready asset，并在 MuJoCo 中重放手—物交互。
- **Coding 接口**：多模型模块化编排、显式几何推理、MuJoCo 资产与轨迹。
- **场景**：扫描现实道具进入游戏或仿真、机器人训练资产生成。
- **成熟度 / 证据 / 重要性 / 阅读**：可运行研究管线；论文实测；中高；可读。

### 12. KoUniTalk：韩英双语 3D 口型评测进入统一拓扑

- **类型**：benchmark / dataset；**主线**：数字人。
- **官方链接与日期**：[arXiv 2609.19840](https://arxiv.org/abs/2609.19840)，2026-09-17。
- **相对上期**：首次收录。

- **Coding 接口**：统一 mesh topology 可直接接入 3D talking-face 训练和自动指标计算。
- **场景**：多语言数字员工、跨语种口型测试、轻量端侧面部驱动。
- **成熟度 / 证据 / 重要性 / 阅读**：benchmark；论文实测；中；可读。

## 4. 数字人 / 虚拟形象能力进展

- **生成与驱动**：VibeAvatar 的实质增量是把语音内容正确性和动作偏好拆到不同训练阶段，避免一个生成器同时承担音素、身份和审美目标。它仍是单次离线生成论文，未证明流式输入、打断或多人对话。
- **3D/4D 表示**：本周期没有新的高质量 4D avatar 主模型；KoUniTalk 的统一轻量 mesh 更偏评测基础设施。
- **实时交互**：真正可用于产品的新变化来自 LiveKit，而非新的渲染论文。agent 音频、数字人视频和前端均通过标准 RTC track 解耦，支持角色切换、异常捕获和音频降级。
- **音视频与情感**：VibeAvatar 优化“人类偏好的动作审美”，但不是显式情绪控制；目前仍缺少情绪、视线、手势和 turn-taking 的联合公开评测。
- **工程部署**：LiveKit–Synthesia 已进入正式 SDK；VibeAvatar 仅有论文指标；KoUniTalk 是训练与验收资产。
- **安全与身份治理**：本周期未发现达到收录标准的新水印、授权或肖像溯源发布。数字人运行时进展快于身份治理，生产系统仍需自行维护肖像授权、录制留存和生成内容标识。

## 5. 世界模型进展

- **架构与训练**：JEPA-Anything 强调可重用 latent prediction interface；PointZero 则用与 embodiment 无关的点轨迹任务吸收更多非机器人数据。
- **可控与可行动**：MoWAM 表明部署时不一定需要生成可观看视频，只需保留足以选择动作的未来运动表示。
- **长时与记忆**：Workspace Models 把高成本历史分析搬到训练期，部署时只读取轻量 token；这比无限增长上下文更接近可持续运行。
- **空间表示**：PointZero、ParticleSplat 和 Track, Articulate, Act 都指向对象中心的 3D 状态。ParticleSplat 还展示了通过修改 latent particle 直接移动对象的可编辑性，但尚未形成通用运行时。[论文](https://arxiv.org/abs/2609.19463)
- **机器人、游戏与仿真**：WorldContact、DexTouch-WM、ReShoot 均给出真实机器人证据；本周期没有同等级的新可玩游戏世界模型。
- **实时部署与评测**：MoWAM 的非视频推理和 WorldContact 的大步长 rollout 都在降成本；但多数论文没有披露端到端控制周期、并发、故障恢复和长期运行稳定性。

## 6. Coding × 新型互动作品

### 链路一：实时多角色数字员工

**LLM/工具调用 → LiveKit `AgentSession` → Synthesia `AvatarSession` → RTC 音视频轨道 → 客服、导购或主持人**

代码负责身份鉴权、业务状态、工具调用、角色切换、打断与失败降级；数字人服务负责从音频生成同步表演；RTC 负责传输和参与者生命周期。已有正式 SDK 与示例代码，属于可运行产品链路，但价格、端到端延迟和大并发能力未在本次发布中披露。

### 链路二：可验证的机器人 coding agent

**自然语言任务 → coding agent 生成技能程序 → waypoint/接触 harness 验证 → 冻结 VLA/控制器执行 → 失败重规划**

SafeHarness 证明，语言指令中的安全要求必须编译成几何检查和执行门禁。相同架构可以迁移到游戏 NPC：LLM 负责意图和策略，导航网格、碰撞系统及权威服务器决定动作是否允许。机器人链路已有论文实验；NPC 迁移属于本报告推断。

### 链路三：低延迟世界—动作推理

**观察与任务 → MoWAM 采样未来运动—动作对 → progress verifier 排序 → 传统控制器执行**

生成模型不再渲染完整未来画面，代码层只消费结构化运动和评分。这更适合工厂控制、边缘机器人和高频交互，代价是失去人类可直接观看的 rollout，需要额外可解释日志。

### 链路四：真实视频到可交互仿真资产

**单目视频 → 点轨迹/部件分割 → 关节与状态估计 → MuJoCo 资产 → 机器人或互动作品**

模型负责视觉重建，显式几何代码负责关节合法性、碰撞体和坐标对齐，仿真器负责接触与规则。可用于快速把现实中的抽屉、柜门、设备面板变成训练环境，也可生成互动展览中的数字孪生道具。已有项目 demo，尚非自动化生产工具。

### 链路五：生成式数据工厂

**录制演示 → VLM 改写属性 → 视频模型重渲染 → 多视图/标签校验 → 策略训练与回归测试**

ReShoot 中，生成模型只改变外观，动作和本体感觉仍由原始记录提供；代码必须验证帧间一致性、相机同步和标签仍然有效。其商业价值不是生成视频成品，而是减少为每种颜色、材质和背景重新操作机器人的成本。

### 链路六：触觉驱动的交互代理

**人类触觉采集 → 动作重定向 → 视觉—触觉世界模型 → 候选抓取 rollout → 机器人执行**

DexTouch-WM 把人类交互变成机器人预测数据，未来也可驱动触觉游戏角色、远程操作和培训模拟器。当前可运行证据局限于研究硬件和特定任务，传感器标定及跨手型迁移仍是主要门槛。

## 9. 系统架构与技术趋势判断

1. **明显升温**：任务相关状态表示。运动、接触、触觉、点轨迹和记忆 token 正在替代无差别 RGB rollout。
2. **趋向主流**：训练期使用大模型和高成本生成器，部署期蒸馏成结构化 latent、轻量策略或 verifier。
3. **可复用架构**：`感知 → 结构化世界状态 → 候选动作/内容 → 规则与安全验证 → 权威执行器 → 事件日志与回退`。数字人、NPC 和机器人只是不同的渲染与执行后端。
4. **Coding 的角色变化**：代码不再只生成一次性内容，而是维护会话、状态、权限、约束、工具、观测、重试和成本预算；生成模型负责外观、预测与候选方案。
5. **尚未解决**：跨小时状态漂移、世界模型置信度校准、合成数据偏差、实时审核、肖像授权、跨供应商 avatar 行为一致性，以及真实生产并发和单位成本。
6. **需要降级看待**：没有代码、权重或可调用接口的“实时”论文只能视为实验室指标；只展示画面而不提供动作协议、状态持久化和闭环评测的 world model 仍是视频 demo。
7. **产业判断**：本周期最可信的产品增量是 LiveKit 插件与 tracing，而不是新的基础模型。它解决了数字人如何进入软件系统的问题，但没有解决数字人的真实性、安全和经济性。

## 10. 论文精读候选

1. **[Coding Agents with an Obstacle-Aware Harness](https://arxiv.org/abs/2609.20822)**  
   值得读：直接回答 coding agent 如何进入物理闭环。重点看任务分解、route/contact harness、消融和失败案例。与纯提示安全相比，它把约束变成可验证程序。复现风险是基座模型、VLA 和 SafeLIBERO 环境依赖较多。

2. **[MoWAM](https://arxiv.org/abs/2609.20709)**  
   值得读：代表 WAM 从“生成可视未来”转向“预测足够用于控制的未来”。重点看 motion representation、Mixture-of-Transformer、候选采样与 verifier。复现风险是论文摘要未给出代码和端到端时延。

3. **[WorldContact](https://arxiv.org/abs/2609.19600)**  
   值得读：把世界模型的速度收益连接到 VLA 微调和真实机器人成功率。重点看接触状态表示、时间步设计、仿真数据扩充和真实转移。复现风险是数值模拟器、H100 与真实柔性物体实验成本较高。

4. **[PointZero](https://arxiv.org/abs/2609.19142)**  
   值得读：提供可跨 embodiment 的 3D 动力学预训练目标。重点看 point-track completion、生成式目标消融、数据构造及后训练接口。复现风险是 290 万帧数据和 RGB-D/相机标定。

5. **[VibeAvatar](https://arxiv.org/abs/2609.18632)**  
   值得读：数字人目标拆解清晰。重点看 PKA、AMP/GRPO、主观评测和显存/速度测量方法。与端到端音频扩散相比，它把口型与审美放在不同阶段。最大风险是尚无公开代码，且“接近实时”未包含网络、音频缓冲和打断。

## 11. 下周跟踪与可行动建议

### 继续跟踪

1. VibeAvatar 是否开放代码、权重及真正的 chunk-causal 流式推理。
2. LiveKit–Synthesia 的首帧延迟、打断恢复、并发上限、价格和区域可用性。
3. SafeHarness 是否开放 benchmark、路径验证器及真实机器人实验。
4. MoWAM 去除视频生成后的实际控制频率，以及 verifier 的额外计算成本。
5. WorldContact 的 10× 加速在包含渲染、I/O 和策略训练后还剩多少。
6. DexTouch-WM 的合成轨迹为何在部分策略配置中不能稳定超过纯真实数据。
7. PointZero 能否从普通 RGB 视频而非 RGB-D 稳定获得可用的 3D 轨迹条件。
8. KoUniTalk 数据、处理脚本、许可证和更多语言扩展是否真正开放。

### 本周可做的小实验

1. **实时多角色数字员工**
   - 目标：验证角色切换、打断和失败降级是否能连续运行 30 分钟。
   - 组件：LiveKit Agents 1.8.2、Synthesia 插件、任一 LLM/TTS、简单 CRM mock。
   - 难点：API 套餐、音视频同步、avatar worker 断线。
   - 成功判据：20 次轮次中断无死锁；两次角色切换不重建用户连接；数字人失败时 2 秒内降级为纯音频。

2. **结构化未来与视频未来的成本对照**
   - 目标：验证 MoWAM 式运动状态是否足以替代视频 rollout。
   - 组件：LIBERO、小型轨迹预测器、视频预测基线、任务进度 verifier。
   - 难点：保证两种方案使用相同观察和动作预算。
   - 成功判据：任务成功率下降不超过 5 个百分点，同时中位决策时延至少下降 50%。

3. **生成式演示数据的一致性门禁**
   - 目标：复现 ReShoot 的最小数据管线并检测“画面变了但动作标签失效”。
   - 组件：10 条双视图演示、VLM caption、可控视频编辑器、光流/点轨迹校验。
   - 难点：双相机时间一致性和接触点漂移。
   - 成功判据：人工抽检通过率超过 90%，且增强数据不降低原始场景成功率。

4. **视频到可交互道具**
   - 目标：把一段抽屉或柜门视频转换为可在 MuJoCo 中操作的关节资产。
   - 组件：Track, Articulate, Act 管线或同类 3D 跟踪器、mesh 分割、MuJoCo。
   - 难点：尺度恢复、关节轴估计、碰撞体简化。
   - 成功判据：关节类型正确，轴线误差不影响开合，仿真中可连续完成 20 次无穿透操作。
