# 数字人、世界模型与互动作品研究日报：2026-10-30

检索窗口：2026-10-24 至 2026-10-30。  
信息截点：2026-10-30 09:00（Asia/Shanghai）。已与 10 月 24—29 日日报去重；论文日期按 arXiv 原始提交时间，代码更新按官方仓库记录。

## 1. 本日摘要

最近七天最强的新增信号不是模型尺寸继续增大，而是互动世界模型开始形成较完整的开发者栈。Hy-Nomas 同时开放权重、训练与推理代码、LoRA、Diffusers 接口、Web demo，并已出现 SGLang、ComfyUI、Reactor Runtime 和 WanGP 集成；这使“连续生成视频”第一次较完整地接上流式服务、节点工作流和浏览器交互。

Hy-Nomas 的重要设计是把长期有效的场景描述与只在特定时间窗生效的动作指令分开，避免角色重复执行历史动作；Prompt Enhancer 则把自然语言和视频历史编译为结构化条件。它已经是可运行研究平台，但空间重访仍弱于 Genie 3，且没有公开并发、p95 端到端延迟或服务成本。

WorldCrafter 在 10 月 28 日新增 144 组测试样本，使相机可控、带隐式 3D 记忆的世界模型有了更明确的回归测试入口；相比前期仅有模型和 runtime，工程可验证性进一步提高。

TAPESTRY 展示了另一条世界模型产业路径：视频模型的物理先验不一定要在推理时生成视频，也可以把机器人动作编码成“视频 patch”，在 84 ms 内直接输出动作块。其价值更多在控制系统，而非面向用户的可玩视频。

数字人方向本周期没有新的高质量实时 talking-head、口型同步、全双工情感或虚拟主播产品发布。新增集中在困难视频中的 3D 人体网格恢复、一步身份替换，以及 Gaussian Splatting 的隐私治理；能力有所补齐，但没有改变数字员工、虚拟主播的成熟度判断。

基础设施方面，FVQ 表明离散视觉 token 的语义上限未必由重建误差决定；若能避免多码本信息递减，离散视觉表示可接近连续表示。这对未来统一处理世界状态、视频、动作和代码 token 有意义，但目前实测重点仍是图像理解而非视频世界模型。

产业证据仍以论文作者实测、开源组件和社区集成为主；本周期未发现新增的客户试点或规模化部署。最明确的趋势是：代码负责状态、接口、路由和验收，生成模型负责开放视觉与语义变化，传统引擎或控制器继续承担权威规则、物理和安全边界。

## 3. 最值得关注的 8 个进展

### 1. Hy-Nomas：多轮自然语言与相机控制进入开放运行时

- **类型 / 日期 / 主线：**模型、论文、GitHub、权重、benchmark、demo；技术报告 2026-10-27，runtime 集成与对比材料更新至 10-29；世界模型、Coding × 互动作品。
- **官方链接：**[论文](https://arxiv.org/abs/2610.36729)、[代码](https://github.com/Tencent-Hunyuan/Hy-Nomas)、[权重](https://huggingface.co/tencent/Hy-Nomas)、[benchmark](https://huggingface.co/datasets/tencent/Hy-Nomas-Bench)。
- **相对上期的新变化：**首次作为重点收录。10 月 26—29 日新增 SGLang、ComfyUI、Reactor Runtime 等社区集成和完整技术报告；不只是新增 demo。
- **核心贡献：**8B DiT 以 segment-wise causal attention 持续生成；action-aware mask 让场景描述跨段保留、动作指令仅在指定时间窗生效。Prompt Enhancer 将用户请求、对话和视频历史转换为结构化 prompt 与下一段时长。
- **作者实测：**1280×704、24 FPS 的七段共 100 秒生成，单 RTX 4090 峰值显存 20.53 GiB；这是显存数据，不代表实时速度。280 项 Hy-Nomas-Bench 中，空间记忆仍落后 Genie 3。[论文评测](https://arxiv.org/html/2610.36729v1)
- **Coding 接口：**Apache-2.0；提供 Python/Diffusers、JSON 条件、LoRA、Docker、Web demo，并已接入 SGLang 流式会话、Reactor 浏览器服务、ComfyUI 和 WanGP。
- **场景：**可导演互动电影、连续品牌空间、生成式游戏视觉层、机器人视觉模拟。
- **成熟度 / 证据：**已开源、可运行 demo；论文实测＋社区集成，尚无客户部署。
- **重要性 / 阅读：**高 / 必读。

### 2. TAPESTRY：视频世界模型直接输出机器人动作

- **类型 / 日期 / 主线：**论文、机器人策略；2026-10-27；世界模型、机器人。
- **官方链接：**[论文](https://arxiv.org/abs/2610.36823)、[项目页](https://tapestry-wam.github.io/)。
- **相对上期的新变化：**首次收录，补充了“视频生成先验如何脱离视频渲染成本、直接服务控制”的证据。
- **核心贡献：**将动作时间步映射为视频 VAE patch 维度的 token，与视频 latent 共用 Transformer；联合训练视频扩散、视频＋动作扩散和纯动作扩散。
- **作者实测：**推理时不生成完整视频，以单步 DDIM 生成动作块，在消费级硬件上报告 84 ms/块，并完成仿真和真机实验。
- **Coding 接口：**目前主要是模型策略接口；未见完整公开代码、机器人中间件插件或安全控制 API。
- **场景：**机械臂、具身 agent、视频先验驱动的低成本策略。
- **成熟度 / 证据：**论文研究原型；作者实测。
- **重要性 / 阅读：**高 / 必读。

### 3. WorldCrafter：新增可下载的世界模型测试集

- **类型 / 日期 / 主线：**GitHub、权重、benchmark、runtime；benchmark 更新 2026-10-28；世界模型、Coding × 互动。
- **官方链接：**[代码与更新记录](https://github.com/TencentARC/WorldCrafter)。
- **相对上期的新变化：**项目本身早于窗口；本次纳入原因是新增 144 组“第一人称探索＋第三人称主体跟随”图像—prompt 测试对。10 月 22 日还开放了微调管线、部分训练数据和 Reactor Runtime 推理。
- **核心贡献：**用相机可查询的隐式 3D-aware memory 支撑跨视角和长时探索；Base 与蒸馏 Fast 权重均开放。
- **Coding 接口：**Python CLI 接收图像、文本和 `.npy` 相机轨迹；浏览器 demo 支持键盘控制；可接 Reactor 服务。
- **场景：**可探索概念空间、游戏预演、虚拟摄影、世界模型回归测试。
- **成熟度 / 证据：**已开源研究平台；官方代码和数据，生产指标未披露。
- **重要性 / 阅读：**高 / 必读。

### 4. FVQ：离散视觉 token 接近连续表示

- **类型 / 日期 / 主线：**论文、GitHub、模型权重；2026-10-27；支撑基础设施。
- **官方链接：**[论文](https://arxiv.org/abs/2610.37662)、[代码与权重](https://github.com/hustvl/FVQ)。
- **相对上期的新变化：**首次收录。
- **核心贡献：**Factorized Vector Quantization 用并行、对称码本量化完整视觉特征的互补投影，避免 RVQ 后续码本和 PQ 窄分组的信息递减。作者指出重建误差并不能可靠预测下游语义保真度。
- **结果：**FVQ-8B 在九项理解指标平均分上优于作者复测的 UniAR 和 Emu3-Chat，并在部分 OCR/文档任务接近连续 Qwen3-VL；这些不是视频生成或世界模型实测。
- **Coding 接口：**Apache-2.0，含 tokenizer、图像编码、VLM 推理、四阶段训练脚本、测试和权重。
- **场景：**统一视觉—语言—动作 token、低带宽 agent 记忆、可检索世界状态。
- **成熟度 / 证据：**已开源研究组件；论文作者实测。
- **重要性 / 阅读：**中高 / 必读。

### 5. PrinGS：从 3DGS 表示层清除人脸和敏感文本

- **类型 / 日期 / 主线：**论文、dataset、项目页；2026-10-26；安全与身份治理。
- **官方链接：**[论文](https://arxiv.org/abs/2610.36168)、[项目页](https://privacypreserving3dgs.github.io/)、[仓库](https://github.com/privacypreserving3dgs/PrinGS)。
- **相对上期的新变化：**首次收录，为可共享 3D/数字孪生资产增加表示层匿名化方案。
- **核心贡献：**从单个参考视图定位敏感 Gaussian，经多视角可见性聚合和局部体积模糊，在训练后直接修改 splat；也提供 privacy-by-design 训练思路。
- **作者实测：**报告后处理少于 1 秒，整体人脸相似度降至 9.79%，文本 OCR CER 达 1.00。
- **Coding 接口：**项目页给出算法流程，但所谓“Code”仓库截至截点只有 README、无可运行实现，因此不能标为已开源。
- **场景：**室内扫描、数字孪生、空间视频、共享 3D 资产合规。
- **成熟度 / 证据：**论文与数据级原型；作者实测。
- **重要性 / 阅读：**中高 / 必读。

### 6. UT-HMR：困难体育视频中的不确定性人体恢复

- **类型 / 日期 / 主线：**论文；2026-10-26；数字人、人体感知。
- **官方链接：**[论文](https://arxiv.org/abs/2610.36203)。
- **相对上期的新变化：**首次收录。
- **核心贡献：**为完整 SMPL 姿态预测低秩加对角协方差，将相关关节不确定性转换为训练权重；在解码前通过 temporal early fusion 利用邻帧信息。
- **结果：**作者报告在冰球和足球数据上，MPJPE、PA-MPJPE、PVE 最多分别下降 4.7%、3.8%、5.6%。
- **Coding 接口：**未见公开代码或实时 SDK；输出可作为 avatar rig、体育分析或虚拟摄影的人体驱动输入。
- **场景：**远景运动员数字替身、体育转播、多人动捕预处理。
- **成熟度 / 证据：**论文原型；作者实测。
- **重要性 / 阅读：**中 / 可读。

### 7. ALADDIN：一步身份替换与评测偏差修正

- **类型 / 日期 / 主线：**论文；2026-10-27；数字人、安全。
- **官方链接：**[论文](https://arxiv.org/abs/2610.37503)。
- **相对上期的新变化：**首次收录。
- **核心贡献：**从多步 flow-matching 模型初始化一步生成器，以对抗、身份和目标属性约束蒸馏；同时指出用训练时相同 identity encoder 评测会偏袒特定方法。
- **结果：**作者声称在相当身份迁移强度下匹配最佳多步模型，网络执行次数减少 28 倍、训练对数量约少一个数量级。
- **Coding 接口：**未见公开代码、权重、水印或授权检查；不具备产品级身份治理闭环。
- **场景：**经授权数字替身、影视预演；也显著降低滥用成本。
- **成熟度 / 证据：**论文原型；作者实测。
- **重要性 / 阅读：**中 / 可读。

### 8. RGB＋事件相机的轻量 4D 重建

- **类型 / 日期 / 主线：**论文；2026-10-27；4D 表示、AR/VR、机器人。
- **官方链接：**[论文](https://arxiv.org/abs/2610.36610)。
- **相对上期的新变化：**首次收录。
- **核心贡献：**在 Monst3R 上增加事件相机输入分支，其余架构基本不变；用微秒级亮度变化补偿高速运动中的模糊和时间混叠。
- **结果：**三个 benchmark 上相对 RGB-only Monst3R 平均降低 3.4% Abs Rel，运动越剧烈改善越明显。
- **Coding 接口：**尚无公开实现；工程上可作为高速 4D 捕获管线的可选 sensor adapter。
- **场景：**高速表演捕获、机器人操作、运动数字人和 AR。
- **成熟度 / 证据：**初步论文研究；作者实测。
- **重要性 / 阅读：**中 / 可读。

## 4. 数字人 / 虚拟形象能力进展

- **生成与驱动：**本周期暂无新的高质量语音驱动头像、lip-sync、全双工 turn-taking 或情感数字人。ALADDIN 是静态身份替换，不应写成实时数字人突破。
- **3D/4D 表示：**UT-HMR 改善远距离、遮挡和运动模糊下的 SMPL 恢复；RGB＋事件输入提高高速动态场景重建稳定性。两者可以改善数字人资产输入，但都不是完整 avatar 系统。
- **实时交互：**没有新的数字人端到端延迟或并发数据。世界模型 runtime 的进展不能直接替代 RTC、TTS、口型和可打断会话栈。
- **音视频与情感表达：**本周期暂无高质量新增。
- **工程部署：**UT-HMR、ALADDIN 和事件 4D 重建均未见可直接部署的 SDK；暂不能进入正式产品采购。
- **安全与身份治理：**PrinGS 将匿名化从最终截图提升到 3D 表示层，能覆盖任意新视角；但代码尚未真正开放。ALADDIN 则反向说明身份替换成本继续下降，授权、审计、水印和来源证明更紧迫。

## 5. 世界模型进展

- **架构与训练：**Hy-Nomas 用结构化 caption、时间窗动作和 causal attention 对齐持续世界演化；FVQ 则探索统一离散视觉接口。
- **可控/可玩生成：**Hy-Nomas 支持同一会话内交替使用自然语言、WASD/方向键或相机矩阵，不需在“导演模式”和“探索模式”间重置世界。
- **长时与物理一致性：**滑动窗口 KV cache 控制显存增长，但会丢弃部分历史；其空间重访仍弱于 Genie 3。长期视频连续不等于显式世界状态正确。
- **空间表示：**WorldCrafter 依赖可查询隐式 3D 记忆；Hy-Nomas 主要依赖视频历史和结构化文字。前者偏空间一致性，后者偏开放语义与动作控制。
- **机器人/仿真：**TAPESTRY 证明视频 backbone 可以直接成为动作策略；Hy-Nomas 还提供机器人 LoRA，但视觉模拟结果不能替代接触安全验证。
- **实时部署：**Hy-Nomas 的单卡 4090 数据是显存可运行性，不是实时吞吐；社区 TPU 报告也仍需独立复测。TAPESTRY 的 84 ms 是动作块生成时间，不包含传感、规划与执行。
- **评测：**WorldCrafter 新 benchmark 和 Hy-Nomas-Bench 都在从短片画质转向多轮控制、重访和主体跟随，但仍缺统一的服务延迟、故障恢复与权威状态评测。

## 6. Coding × 新型互动作品

### 链路一：自然语言导演的持续生成世界

**用户指令/相机输入 → Prompt Enhancer → 结构化 JSON 与动作时间窗 → Hy-Nomas → Reactor/SGLang 流式服务 → 浏览器互动世界**

代码负责会话、身份、prompt schema、输入路由、缓存边界和视频传输；模型负责开放语义变化与可见未来；若涉及库存、碰撞、胜负或支付，仍应由传统服务保存权威状态。已有开源运行证据。

### 链路二：节点式互动电影与品牌体验

**剧情状态机 → ComfyUI 节点或 Diffusers Python → 多段生成 → 人工/自动质量门禁 → Web/展厅播放**

创作者可在节点图中编排“角色出现—环境变化—镜头移动”等连续事件。代码保持分支逻辑和回滚点，模型完成难以预制的视觉过渡。已有社区集成，但尚无生产案例和并发数据。

### 链路三：相机可控世界的持续集成

**测试图像与 prompt → `.npy` 相机轨迹 → WorldCrafter-Fast → 生成 rollout → 主体跟随/重访指标 → CI 报告**

10 月 28 日新增的 144 组样本可作为模型升级、蒸馏或 runtime 优化后的回归集。代码负责轨迹、批处理与判分，世界模型负责视觉演化。已有可下载数据和运行代码。

### 链路四：视频先验驱动机器人控制

**摄像头观测 → TAPESTRY shared backbone → 单步动作 token → 安全控制器 → 机械臂**

模型负责从视频先验和示范中推断动作块；代码与传统控制器负责关节限制、碰撞、急停和反馈闭环。论文有真机证据，但接口和代码未开放，不能直接部署。

### 链路五：隐私安全的空间数字孪生

**扫描/3DGS → 敏感区域检测或人工 mask → PrinGS 表示层匿名化 → 资产注册与权限服务 → WebXR/引擎发布**

匿名化发生在 splat 内部，可避免从其他视角重新暴露人脸或屏幕文字。代码负责 mask、资产版本、审计和发布门禁；PrinGS 负责修改 Gaussian。链路合理，但可运行代码仍缺失。

### 链路六：体育数字替身

**多机位或远景比赛视频 → UT-HMR → SMPL 动作 → 角色 retarget → Unity/Unreal → 可交互复盘**

模型负责从弱观测恢复人体姿态，传统引擎负责骨骼、碰撞、镜头和交互。当前属于本报告推断，尚无本周期新增的引擎插件或客户案例。

## 9. 系统架构与技术趋势判断

明显升温的是“生成模型＋结构化控制协议＋流式 runtime＋工作流适配”。Hy-Nomas 的 JSON 条件、Prompt Enhancer、KV cache、Diffusers、SGLang 和 Reactor 已形成接近服务栈的形态。

可复用架构正在收敛为：

1. **权威状态层：**数据库、传统引擎或控制器保存规则、物理、身份、权限和存档。
2. **agent/编译层：**将自然语言编译为结构化 prompt、动作时间窗、相机轨迹或代码调用。
3. **生成/策略层：**世界模型生成视觉观察，或像 TAPESTRY 一样直接输出动作 token。
4. **运行时层：**SGLang、Reactor、Diffusers、WebRTC/WebSocket 负责缓存、调度和流传输。
5. **表现层：**视频世界、数字人、语音、传统3D渲染共同构成用户体验。
6. **验收与治理层：**多轮控制测试、重访一致性、p95延迟、内容审核、身份授权和3D资产匿名化。

离散 token 路线重新升温，但 FVQ 目前证明的是理解语义可保留，不能直接推导出视频重建质量、动作可控性或长时世界状态已经解决。

“端到端视频模型完全替代引擎”的叙事继续降温。Hy-Nomas 自身的空间记忆差距、TAPESTRY 对传统安全控制器的依赖，以及 PrinGS 所需的独立隐私处理，都说明生产系统必须保留显式代码和外部治理层。

需要降级看待的材料包括：Hy-Nomas 与闭源模型的官方对比仍是项目方评测；社区 TPU 实时数据尚缺独立复测；PrinGS 的“Code”链接实际没有实现；ALADDIN 没有授权、水印或滥用防护，不能因一步推理就视为产品。

## 10. 论文精读候选

1. [Hy-Nomas](https://arxiv.org/html/2610.36729v1)：重点读 structured caption、action-aware causal attention、Prompt Enhancer、4090 优化和四类 benchmark。与只接收相机或固定动作的世界模型相比，它更接近开放指令运行时。风险是人评为主、空间记忆仍弱、服务指标缺失。
2. [TAPESTRY](https://arxiv.org/abs/2610.36823)：重点读 action-as-video-patch、三种扩散目标和非视频推理路径。核心差异是共享视频 backbone 而不必测试时渲染视频。风险是代码未开放，84 ms 指标边界需核验。
3. [FVQ](https://arxiv.org/abs/2610.37662)：重点读 bit-budget 分析、FVQ analysis/synthesis 结构和离散—连续表示比较。风险是工业训练数据不可复现，结论尚未扩展到视频。
4. [PrinGS](https://arxiv.org/abs/2610.36168)：重点读跨视角 Gaussian 定位、局部模糊与隐私评测。风险是仓库无实现，FDR 降至39.47%也说明人脸可检测性受到明显影响。
5. [UT-HMR](https://arxiv.org/abs/2610.36203)：重点读低秩协方差、heteroscedastic supervision 和 temporal early fusion。风险是改善幅度有限，尚无实际 retarget 或实时运行数据。

## 11. 下周跟踪与可行动建议

继续跟踪：

1. Hy-Nomas 单卡配置的实际生成速度、首帧延迟和长会话 p95 延迟。
2. SGLang/Reactor 多会话并发时的 KV cache、显存隔离和失败恢复。
3. Hy-Nomas 是否能保存显式对象状态，而不只依靠视觉和文字历史。
4. WorldCrafter 新 benchmark 是否出现第三方复测或统一 leaderboard。
5. TAPESTRY 是否开放代码、ROS/Isaac/真实机械臂接口和安全评测。
6. PrinGS 是否真正上传实现，以及跨视角隐私攻击下是否仍有效。
7. ALADDIN 是否提供授权、内容凭证或深伪检测配套机制。
8. 数字人方向是否出现新的实时语音驱动、情感控制或全双工产品证据。

本周可动手实验：

- **实验一：多轮动作隔离。**用 Hy-Nomas 连续执行“拿起—放下—转身—返回”四段指令。组件为 INT8 checkpoint、Diffusers 或官方 CLI；难点是动作和场景描述结构化。成功判据是旧动作不重复、对象状态在返回后仍可辨认。
- **实验二：世界模型 runtime 对比。**用同一图像和相机轨迹分别运行 Hy-Nomas 与 WorldCrafter-Fast。记录首帧时间、每秒生成耗时、峰值显存、重访一致性。成功判据不是主观画质胜负，而是得到可复用的质量—延迟—记忆曲线。
- **实验三：流式互动原型。**以 Reactor 或 SGLang 接入简单 Web 客户端，代码保存玩家位置、任务状态和回滚点，模型只生成画面。目标是验证“权威代码状态＋生成视觉”的分层；成功判据是模型漂移后可从最近检查点恢复，而不会损坏任务状态。
- **实验四：3D 隐私回归集。**即使 PrinGS 尚不可运行，也可先准备含人脸、车牌和屏幕文字的 3DGS 测试场景，并从20个视角执行人脸相似度、检测率和OCR测试。成功判据是形成可在未来匿名化实现上复用的自动验收脚本。
