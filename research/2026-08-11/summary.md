# 数字人、世界模型与互动作品研究日报：2026-08-11

检索窗口：2026-08-05 至 2026-08-11。  
日期说明：本轮主要新增来自 arXiv 8 月 10 日公开批次，论文实际提交时间多为 8 月 7 日 UTC；以下按实际提交日期标注，不把检索排序或公开批次日期误写成论文提交日期。已与本地截至 8 月 10 日的日报去重。

## 1. 本日摘要

本日高质量增量明显偏向世界模型，数字人生成方向暂无值得重复收录的新模型、代码或产品更新。世界模型的核心变化是“记忆、状态和动作接口”取代单纯画质，成为新一轮系统设计重点：WorldTrace指出长时失败不只是缓存容量不足，而是超出训练范围的RoPE位置使旧记忆无法被寻址。SimWAM进一步证明，视频生成可以只充当训练期动态教师，部署时完全删除视频分支，以较低延迟直接输出驾驶轨迹。AtlasVLA和WNM-3D分别将4D持久空间状态、固定长度3D场景token作为行动模型的长期条件，说明可读写空间状态正成为机器人世界模型的关键中间层。UniJEPA与PSG-JEPA共同强化另一条路线：不渲染未来像素，而是在latent中预测足以规划、且能够被物理状态解释的未来。Coding结合方面，最明确的新接口是可寻址KV槽、可替换视频专家、体素哈希世界状态、场景token、可执行scene program和带实例语义的3D Gaussian。Scenix和InstanceSplat让生成空间更接近可编辑软件资产，但代码开放程度不足：InstanceSplat和MirrorWorld当前仓库均只有README或待办。产业证据仍以论文实测、开源研究代码和作者实机实验为主；没有新增SLA、客户试点或规模化部署。

## 3. 最值得关注的 10 个进展

### 1. WorldTrace：长时世界模型首先需要“找得到”记忆

- **类型 / 时间 / 主线：** 论文、benchmark、项目demo；2026-08-07提交、08-10公开；世界模型、运行时。
- **官方链接：** [论文](https://arxiv.org/abs/2608.07408)、[NVIDIA项目页](https://research.nvidia.com/labs/sil/projects/WorldTrace/)。
- **相对上期的新变化：** 首次纳入；补充MASS权威状态之外的像素生成记忆机制。
- **核心技术：** 将缓存分成近期原始窗口和固定数量摘要槽；每个摘要槽使用训练分布内的虚拟位置。Field writer先消除RoPE相位再聚合，Landmark writer保存场景切换时的原始轨迹。
- **Coding接口：** 可封装成世界模型运行时的`recent_cache + summary_slots + landmark_events`，程序负责槽位预算、场景切换检测、快照和重访请求。
- **结果与场景：** 作者报告时间一致性提升15.5%、LoopBench情景回忆提升19.5%；适合可探索视频世界、互动电影场景重访和长时生成式游戏。
- **成熟度 / 证据：** 项目demo，未发现公共实现；论文实测。
- **重要性 / 阅读：** 高 / 必读。

### 2. SimWAM：视频世界模型只在训练时存在，部署时直接输出驾驶轨迹

- **类型 / 时间 / 主线：** 论文、GitHub、模型权重；2026-08-07提交并发布代码；世界模型、自动驾驶。
- **官方链接：** [论文](https://arxiv.org/abs/2608.07468)、[GitHub](https://github.com/H-EmbodVis/SimWAM/)。
- **相对上期的新变化：** 首次纳入；相对UA-NWM的低延迟latent评分，进一步取消部署期未来预测。
- **核心技术：** Wan2.2-5B视频专家与0.21B—1.02B动作DiT通过联合flow matching训练；隔离注意力阻止动作token读取未来视频，部署时可删除视频分支。随后以FlowGRPO和组合驾驶奖励微调动作专家。
- **Coding接口：** 视频骨干可替换，动作专家可独立扩缩；仓库含监督训练、LoRA强化学习、NAVSIM评测和单样本smoke test。
- **结果与场景：** 作者报告单前视相机NAVSIM PDMS 91.5，并零样本迁移至nuScenes；适用于驾驶规划和低延迟机器人策略。
- **成熟度 / 证据：** 已开源研究栈；论文实测，尚非道路部署。
- **重要性 / 阅读：** 高 / 必读。

### 3. AtlasVLA：用4D体素哈希世界状态弥补腕部相机的“看不见”

- **类型 / 时间 / 主线：** 论文、实机实验；2026-08-07；世界模型、机器人。
- **官方链接：** [论文](https://arxiv.org/abs/2608.06729)。
- **相对上期的新变化：** 首次纳入；将StreamMind的长期记忆思想推进到机器人空间状态。
- **核心技术：** 4D Persistent World State Memory把历史2D观察提升为持续更新的体素哈希状态；Ego-Working State Memory记录自身状态和任务进度，再共同条件化动作DiT。
- **Coding接口：** 可映射为`observation → voxel update → task-state update → action diffusion`；传统控制器仍负责碰撞、安全区和急停。
- **结果与场景：** 作者报告LIBERO-Long绝对成功率提升9.4%，真实长时任务提升17.5%；适合仓储、实验室及服务机器人。
- **成熟度 / 证据：** 论文原型＋作者实机，无确认代码。
- **重要性 / 阅读：** 高 / 必读。

### 4. WNM-3D：把历史几何压缩为固定长度场景token

- **类型 / 时间 / 主线：** 论文、导航世界模型；2026-08-07；世界模型、Coding × 运行时。
- **官方链接：** [论文](https://arxiv.org/abs/2608.07267)。
- **相对上期的新变化：** 首次纳入。
- **核心技术：** 冻结几何编码器从单目历史构建3D表示，Scene-to-Token Adapter将其压缩为固定长度前缀，并通过block-causal attention同时约束未来视图和动作。
- **Coding接口：** 固定长度scene token适合服务端缓存、序列化和跨步骤复用；导航栈可将它与A*示范、DAgger采样和闭环强化学习组合。
- **场景 / 成熟度：** 连续视觉语言导航和虚拟导览；论文实测，代码与时延未披露。
- **证据 / 重要性 / 阅读：** 论文实测 / 高 / 必读。

### 5. UniJEPA：一个latent同时学习图像不变性与视频动力学

- **类型 / 时间 / 主线：** ICML 2026论文；2026-08-07；世界模型。
- **官方链接：** [论文](https://arxiv.org/abs/2608.07409)。
- **相对上期的新变化：** 首次纳入；延续DF³、PhyLatent的非像素未来路线。
- **核心技术：** 用统一的next-embedding损失和Gaussian正则同时训练图像光度变换与视频时间预测，不依赖EMA、stop-gradient或预训练编码器；行动后训练后，以目标特征作为预测目标进行零样本规划。
- **Coding接口：** 适合暴露为`state_embedding + candidate_action → predicted_embedding`批量评分API。
- **结果 / 成熟度：** 作者称规划速度比生成式世界模型快数十倍且精度相当；论文原型，未发现代码。
- **证据 / 重要性 / 阅读：** 论文实测 / 高 / 必读。

### 6. PSG-JEPA：可预测未来的latent未必能表达机器人物理状态

- **类型 / 时间 / 主线：** 论文、实机实验；2026-08-07；世界模型、机器人。
- **官方链接：** [论文](https://arxiv.org/abs/2608.06799)。
- **相对上期的新变化：** 首次纳入；与上期PhyLatent结论一致，但增加真实机器人验证。
- **核心技术：** 训练时增加单latent到本体状态、latent对到多时间尺度关节变化的两个grounding目标；部署架构和计算量不变。
- **Coding接口：** 物理probe可作为训练CI，检查latent能否恢复状态和状态差分，再决定是否允许进入规划器。
- **成熟度 / 证据：** 仿真＋作者实机；无确认代码。
- **重要性 / 阅读：** 高 / 必读。

### 7. Scenix：从稀疏照片直接生成可执行scene program

- **类型 / 时间 / 主线：** 论文、dataset；2026-08-07；Coding × 互动作品、3D基础设施。
- **官方链接：** [论文](https://arxiv.org/abs/2608.07012)。
- **相对上期的新变化：** 首次纳入；相对InfiniSplat的纯Gaussian输出，增加房间、对象及布局结构。
- **核心技术：** 从少量未标定RGB图像预测scene program，通过感知约束资产实例化和闭环空间优化恢复可编辑房间；训练集约11万个合成与真实室内场景。
- **Coding接口：** scene program可由coding agent修改对象、尺寸、变换和房间结构，再实例化进游戏或仿真运行时。
- **成熟度 / 证据：** 论文原型；未确认代码、数据许可证或引擎导出格式。
- **重要性 / 阅读：** 中高 / 必读。

### 8. InstanceSplat：3DGS开始携带实例ID与语言语义

- **类型 / 时间 / 主线：** 论文、项目demo、GitHub占位；2026-08-07；3D基础设施、Coding × 互动作品。
- **官方链接：** [论文](https://arxiv.org/abs/2608.07144)、[交互项目页](https://jamchaos.github.io/InsSplat/)、[GitHub](https://github.com/JamChaos/InsSplat)。
- **相对上期的新变化：** 首次纳入。
- **核心技术：** 单次前向从无位姿多视图生成同时包含外观、几何、8维实例embedding和语言语义的Gaussian；可跨视图选择完整对象。
- **Coding接口：** 运行时可通过实例ID隐藏、替换或查询对象，并以文本定位3D对象，比不可分组的Gaussian云更适合作为交互资产。
- **成熟度 / 证据：** 项目页已有交互式实例移除demo；GitHub目前仅README，无实现与许可证。
- **重要性 / 阅读：** 中高 / 可读。

### 9. Surg-UniWorld：用多模态控制专家约束手术视频世界

- **类型 / 时间 / 主线：** 论文、benchmark；2026-08-07；世界模型、医疗仿真。
- **官方链接：** [论文](https://arxiv.org/abs/2608.06770)。
- **相对上期的新变化：** 首次纳入。
- **核心技术：** 首帧和分层语义mask构成持久手术锚点，edge、depth和optical flow专家相对锚点编码，再组合为Wan2.2控制提示；同步提出Cholec80-SurgWAM。
- **Coding接口：** 仿真器可按任务启用不同控制专家，并将解剖mask、器械轨迹和深度作为独立条件通道。
- **成熟度 / 证据：** 论文原型；没有代码、临床验证或实时数据。
- **重要性 / 阅读：** 中高 / 可读。

### 10. PS-FNVD：合成视频安全从二分类升级为来源与叙事联合判断

- **类型 / 时间 / 主线：** dataset、benchmark、检测模型；2026-08-07；安全基础设施。
- **官方链接：** [论文](https://arxiv.org/abs/2608.06732)。
- **相对上期的新变化：** 首次纳入；补充上期身份生成能力缺少治理机制的问题。
- **核心技术：** 将新闻视频分为真实、廉价拼接假视频和纯合成假视频；同时覆盖虚构事件和“真实事件、虚假画面来源”，联合语义逻辑与生成痕迹。
- **Coding接口：** 可部署在数字人或生成视频发布管线中，对叙事、素材来源及生成痕迹分别打标。
- **结果 / 成熟度：** 作者报告较次优基线准确率提升12.20个百分点；论文实测，未确认公共数据入口。
- **重要性 / 阅读：** 中 / 可读。

## 4. 数字人 / 虚拟形象能力进展

**生成与驱动、3D/4D、实时交互、音视频与情感：** 本周期暂无高质量新增。8月3日提交的SubtleTalk虽提供韵律、局部强度和Valence-Arousal控制，并构建约3,900身份、74小时3D面部数据，但实际日期早于本报告窗口，且没有窗口内实质更新，故不作为今日增量重复收录。

**工程部署：** 上期Wan-Animate-2仍是当前最明确的开放入口，但公开14B版本的多卡需求没有变化；Vorch-Streamer仍未开放流式API。今日世界模型的可寻址缓存和持久状态未来可迁移到长时数字人，用于保存服装、背景、聆听姿态和会话阶段，但这是本报告推断。

**安全与身份治理：** PS-FNVD提供的是新闻视频检测，不等同于肖像授权、水印或C2PA。本期仍无新的数字人授权、活体同意和内容凭证方案。

## 5. 世界模型进展

- **架构与训练：** SimWAM证明世界模型可以成为训练期教师；UniJEPA和PSG-JEPA则把世界建模收缩到可规划latent。
- **可控与可玩：** WNM-3D使用3D场景token共同约束未来观察和动作；Surg-UniWorld将edge、depth、flow变成可组合控制专家。
- **长时一致性：** WorldTrace把问题定位到“寻址失败”，而非简单缓存不足；AtlasVLA从生成记忆转向可更新4D空间状态。
- **空间表示：** voxel hash、scene token、scene program和instance-aware Gaussian正在成为程序与模型共享的中间表示。
- **机器人与仿真：** SimWAM代码开放度最高；AtlasVLA、PSG-JEPA和C2Dex有作者实机证据，但尚无生产安全认证。
- **实时部署与评测：** 本批次没有新的可玩视频FPS或端到端交互时延。SimWAM的低延迟是“删除视频生成”的结果，不能外推为实时生成能力。

## 6. Coding × 新型互动作品

1. **玩家输入与相机轨迹 → WorldTrace缓存管理器 → 视频世界重访 → 可探索互动电影。**  
   程序负责场景切换事件、摘要槽、地标快照和缓存回收；模型负责新视图生成。已有论文demo，无开放运行时。

2. **稀疏照片 → Scenix scene program → coding agent修改对象与规则 → Unity/Unreal空间原型。**  
   代码持有对象ID、变换、碰撞和脚本；生成模型恢复房间和资产；传统引擎执行物理、导航与联网。scene program有论文证据，引擎导出属于本报告推断。

3. **无位姿多视图 → InstanceSplat语义3DGS → 文本查询/实例事件 → 可编辑品牌展厅。**  
   模型生成可渲染空间；代码按实例选择、隐藏或替换对象；Web/引擎负责交互。项目页已有实例移除demo，推理代码未开放。

4. **历史单目观察 → WNM-3D场景token → 导航策略 → 虚拟导游或机器人导览。**  
   代码负责地图会话、目标、超时和安全回退；模型联合预测未来视图与动作。当前只有论文闭环评测。

5. **腕部相机 → AtlasVLA体素世界状态＋任务状态 → 动作DiT → 长流程机器人助手。**  
   模型负责感知与动作建议，体素状态保存离开视野的物体；传统控制器负责可执行性。已有作者实机，未形成SDK。

6. **训练视频 → SimWAM视频专家 → 删除视频分支 → 低延迟行动服务。**  
   这是“生成内容”向“用生成知识训练运行时”的另一种Coding链路：生产代码只部署动作专家，视频模型留在训练管线。仓库已可运行，但仅限研究评测。

| 机器人/仿真 | SimWAM/AtlasVLA/WNM-3D＋安全控制器 | 持续状态更新与闭环规划 | 开源研究栈＋作者实机 | SimWAM具体时延未披露 | 域外失效、安全认证 | [SimWAM代码](https://github.com/H-EmbodVis/SimWAM/) |

## 8. 可复现资源与开发者入口

- [SimWAM](https://github.com/H-EmbodVis/SimWAM/)：本期唯一确认具备实质训练、FlowGRPO、NAVSIM评测和checkpoint smoke test的新仓库。许可证需结合NAVSIM、nuPlan、OpenScene和Wan2.2上游条款核查；完整训练示例使用4节点×8 GPU，不适合轻量复现。最小路径是下载监督checkpoint并运行单样本、两步、无视频保存评测。
- [InstanceSplat](https://github.com/JamChaos/InsSplat)：当前仅README，没有推理代码、权重或许可证；可先使用[网页demo](https://jamchaos.github.io/InsSplat/)验证实例选择与文本定位，不建议现在投入本地复现。
- [MirrorWorld](https://github.com/YoujunZhao/MirrorWorld)：仓库明确将推理代码、checkpoint和训练代码列为待办；项目页仅可验证结果展示。
- [WorldTrace项目页](https://research.nvidia.com/labs/sil/projects/WorldTrace/)：含LoopMem案例和定量结果，但未发现公共代码。可自行做简化验证：对现有视频世界模型比较滑动窗口、原始KV平均与消相位后的摘要缓存。
- Scenix、WNM-3D、AtlasVLA、PSG-JEPA、Surg-UniWorld和PS-FNVD均未确认公共实现或权重，当前以论文精读和接口设计为主。

## 9. 系统架构与技术趋势判断

本期最明显升温的是两类状态：一类是生成模型内部的可寻址KV记忆，另一类是程序可读写的3D世界状态。前者解决长视频“见过但找不到”，后者解决机器人和互动系统“画面存在但状态不可查询”。

逐渐成形的复用架构是：

`用户/传感输入 → 可持久世界状态或可寻址记忆 → 候选未来/动作模型 → 规则与物理校验 → 引擎或控制器执行 → 日志回写`

代码负责身份、对象ID、事件、权限、缓存、重放、回退和安全；生成模型负责开放式外观、补全和不确定未来；传统引擎负责碰撞、网络同步和确定性规则；行动模型只消费必要的世界特征。

需要降级看待的项目包括：InstanceSplat的“Code”链接目前只是占位仓库；MirrorWorld的GitHub没有实现；UniJEPA“快数十倍”是作者实验，缺公共基准脚本；AtlasVLA的成功率提升不等于通用机器人可靠性；Scenix的“可执行”尚未证明能直接导入主流引擎。

关键未解问题仍是长时生成状态与结构化状态是否一致、世界记忆的容量和错误淘汰、多人并发成本、实时生成延迟、跨小时对象持久性，以及数字人授权、水印和可打断对话。

## 10. 论文精读候选

1. [Addressable Memory for Video World Models](https://arxiv.org/abs/2608.07408)：重点读RoPE越界分析、canonical-key聚合、Landmark检测和LoopBench协议。差异是把长时漂移重新定义为记忆寻址问题；风险是无代码。
2. [SimWAM](https://arxiv.org/abs/2608.07468)：重点读隔离注意力、联合flow matching、视频分支消融和FlowGRPO奖励。价值在于清晰展示训练期世界模型、部署期轻策略的工业分工。
3. [AtlasVLA](https://arxiv.org/abs/2608.06729)：重点读体素哈希更新、world/ego双记忆及真实机器人评测。复现风险是地图误差累积和未公开实现。
4. [WNM-3D](https://arxiv.org/abs/2608.07267)：重点读3D Scene-to-Token Adapter、block-causal联合生成和闭环训练。差异在于固定长度空间前缀同时约束观察与动作。
5. [PSG-JEPA](https://arxiv.org/abs/2608.06799)：重点读物理状态probe、多时间尺度变化目标和实机迁移。风险是训练期状态标签成本及跨机器人泛化。

## 11. 下周跟踪与可行动建议

继续跟踪：

1. WorldTrace是否开放缓存实现、LoopBench数据及对不同视频骨干的适配。
2. SimWAM checkpoint、许可证和实际动作分支端到端时延能否独立复现。
3. InstanceSplat何时开放推理代码、权重及3DGS文件导出。
4. Scenix是否公布scene program schema、11万场景数据和Unity/Unreal导出器。
5. AtlasVLA在地图错误、对象移动和长时间遮挡下如何更新或撤销旧状态。
6. WNM-3D固定token在长路线和动态场景中是否发生容量饱和。
7. Vorch-Streamer及Wan-Animate-2 Lite是否补充流式、单卡、首帧和打断指标。
8. PS-FNVD是否开放数据，以及检测器对未见T2V模型的泛化能力。

本周可做的小实验：

1. **可寻址缓存原型：** 在现有自回归视频管线中实现近期窗口＋8个固定位置摘要槽。难点是RoPE相位转换；成功判据是往返场景CLIP相似度优于滑动窗口且显存保持恒定。
2. **语义3DGS互动原型：** 使用现有3DGS和人工实例mask模拟InstanceSplat输出，在Web端实现文本选择、隐藏和替换。成功判据是所有视角操作同一对象组且帧率保持可交互。
3. **训练期世界模型消融：** 在小型行为数据集上比较纯动作训练与“视频预测辅助训练、部署删除视频头”。成功判据是部署延迟不增加，同时闭环成功率或轨迹误差显著改善。
4. **scene program到引擎验证：** 设计最小JSON schema，包含房间、对象、变换、语义和碰撞体，由coding agent生成并导入Godot或Three.js。成功判据是可自动实例化、修改、保存和重放同一场景。
